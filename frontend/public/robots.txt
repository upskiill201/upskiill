# =============================================================
# robots.txt — Teyro (https://teyro.app)
#
# Policy: everything is public and crawlable by default — the homepage,
# /courses, /start, the blog, features, use cases, comparisons, /teach and
# every /learn-* page — for search engines AND AI/LLM crawlers alike.
# Only the signed-in app, auth screens, checkout and internal routes are
# blocked (they hold no public content).
#
# Why open-by-default: this file used to be an allow-list that ended in
# "Disallow: /" for Googlebot, Bing and others, so any page not named in it
# (/learn-coding, /learn-ai, /learn-online, /courses, /start, images in
# .webp) was silently blocked. A new public page is now indexable the day it
# ships; to keep something out, add it to the Disallow list below (and give
# it a noindex).
#
# One group for every crawler: a bot that matches a named group ignores the
# "*" group entirely, so separate per-bot blocks would each need the same
# Disallow list. Keep this single list as the source of truth, and
# lib/seo/__tests__/robots.test.ts proves every sitemap URL is allowed.
# =============================================================

Organisation turns effort into results.

## Direct answer

Keep a spreadsheet with a row per application: company, role, link, date applied, status, contact, follow-up date and notes. Review it weekly to follow up and adjust your approach.

## Suggested columns

| Column | Purpose |
| :--- | :--- |
| Company | who |
| Role | what |
| Link | find it again |
| Date applied | timeline |
| Status | applied, interviewing, offer |
| Contact | person |
| Follow-up date | reminder |
| Notes | learning |

## Habits

1. Add each application immediately.
2. Set follow-up reminders.
3. Note what version of your resume you used.
4. Review results monthly.

Was it worth it?

## Direct answer

ROI, or return on investment, measures how much you gain compared with what you spent. The formula is ROI = (gain − cost) ÷ cost × 100. A project that costs 1,000 and returns 1,300 has an ROI of 30 percent.

## Example

| Item | Amount |
| :--- | :--- |
| Cost | 1,000 |
| Return | 1,300 |
| Net gain | 300 |
| ROI | 30% |

## Limits

- It ignores time. A 30 percent return in a year differs from one over five years.
- It ignores risk.
- Some benefits are hard to measure.

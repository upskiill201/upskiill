Almost every app you use stores information in a database. SQL is how you ask it questions.

## Direct answer

SQL (Structured Query Language) is the standard language for working with relational databases, which store data in tables of rows and columns. With a few commands you can read data (`SELECT`), filter it (`WHERE`), summarise it (`GROUP BY`) and combine tables (`JOIN`).

## A table

A database table looks like a spreadsheet:

| id | film | seats_sold | price |
| ---: | :--- | ---: | ---: |
| 1 | Starlight | 120 | 9 |
| 2 | Moonrise | 80 | 8 |
| 3 | Sunset | 150 | 9 |

## Core commands

### Read everything

```sql
SELECT * FROM shows;
```

### Pick columns and filter

```sql
SELECT film, seats_sold
FROM shows
WHERE seats_sold > 100;
```

### Sort

```sql
SELECT film FROM shows ORDER BY seats_sold DESC;
```

### Summarise

```sql
SELECT price, SUM(seats_sold) AS total_seats
FROM shows
GROUP BY price;
```

### Combine two tables

```sql
SELECT customers.name, bookings.seat
FROM bookings
JOIN customers ON customers.id = bookings.customer_id;
```

### Change data

```sql
INSERT INTO shows (film, seats_sold, price) VALUES ('Aurora', 0, 9);
UPDATE shows SET price = 10 WHERE film = 'Moonrise';
```

Always use `WHERE` with `UPDATE` and `DELETE`, or you'll change every row.

## Where SQL is used

- Apps and websites
- Business reports and dashboards
- Finance, health, logistics
- Data analysis. See [how to become a data scientist](/blog/how-to-become-a-data-scientist).

## Different database systems

SQLite, MySQL, PostgreSQL and SQL Server differ slightly, but the core is the same.

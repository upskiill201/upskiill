Netlify makes deploying feel like magic: push code, get a live site.

## Direct answer

You can deploy to Netlify by dragging a folder of site files into its dashboard, or by connecting a Git repository so every push triggers a new deploy. Set the build command and publish directory if your site needs a build step.

## Two ways to deploy

**Drag and drop:** sign in, choose Add new site, then drag your site's folder (with `index.html`) into the page.

**From Git:**
1. Push your project to GitHub.
2. Choose **Import from Git**.
3. Select the repository.
4. Set the build command and publish directory, such as `npm run build` and `dist`.
5. Deploy.

## Handy features

- Automatic HTTPS.
- Deploy previews for branches.
- Form handling for simple contact forms.
- Custom domains.

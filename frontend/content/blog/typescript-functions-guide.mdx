Typing functions is the most useful thing you can do in TypeScript.

## Direct answer

Annotate each parameter, and optionally the return type. Use `?` or a default value for optional parameters, `...rest` for variable arguments and `void` for functions that return nothing.

## Examples

```typescript
function add(a: number, b: number): number {
  return a + b;
}

function greet(name: string, greeting = "Hello"): string {
  return `${greeting}, ${name}`;
}

function log(message: string, level?: "info" | "error"): void {
  console.log(level ?? "info", message);
}

function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0);
}
```

## Function types

```typescript
type Callback = (error: Error | null, data?: string) => void;
const run = (cb: Callback) => cb(null, "done");
```

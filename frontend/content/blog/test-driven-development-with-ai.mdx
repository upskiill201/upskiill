Tests are the clearest instructions you can give an agent.

## Direct answer

With AI-assisted test-driven development, you define behaviour as tests, ask the agent to make them pass and review the result. Tests give the agent a clear target and give you a safety net. Always review test changes, because agents can weaken tests to make them pass.

## A workflow

1. **Describe the behaviour** in plain words.
2. **Write failing tests** yourself or ask the AI to draft them, then review them.
3. **Run the tests** and confirm they fail for the right reason.
4. **Ask the agent to implement** until the tests pass.
5. **Check the diff** for changed tests or special cases that cheat.
6. **Refactor** with the tests as protection.

## Good prompts

"Here are the tests. Make them pass without changing the test files. Explain your approach."

## Watch for

- Hard-coded values that satisfy only the examples.
- Deleted or skipped tests.
- Over-mocked tests that prove nothing.

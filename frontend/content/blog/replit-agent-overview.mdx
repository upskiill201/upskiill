Replit puts an editor, a runtime and an AI agent in one tab.

## Direct answer

Replit Agent is an AI feature inside Replit that plans, writes and runs code for apps from your instructions. Because Replit runs in the browser, you can build and preview without local setup. Keep tasks small, review the changes and check current features and limits on Replit's site.

## A typical flow

1. **Describe your app.**
2. **Review the plan** the agent proposes.
3. **Let it build,** then test the result.
4. **Ask for fixes** with specific feedback.
5. **Deploy** from the same environment.

## Tips

- State your tech preferences, such as language or framework.
- Ask it to explain files you do not understand.
- Use version history or checkpoints.
- Avoid putting secrets in code. Use the secrets feature.

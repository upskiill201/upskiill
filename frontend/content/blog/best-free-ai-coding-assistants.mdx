You can try AI coding help without paying, but free tiers come with limits and they change often. Here is how to approach it, and where to look.

## Direct answer

Several tools have offered free tiers: **GitHub Copilot** (a free plan, and free access for verified students), **Cursor** (a free plan with limits), **Google's Gemini coding tools**, **Windsurf**, and open-source options such as **Continue**. Check each provider's current terms, because limits, models and offers change. Try one at a time on the same small project.

## Free options to look at

| Tool | What it is | Free access (check current terms) |
| :--- | :--- | :--- |
| GitHub Copilot | Autocomplete, chat and agent features in VS Code and other editors | A free plan with limits, and student access through GitHub Education |
| Cursor | AI code editor | A free plan with limits |
| Gemini Code Assist and Gemini CLI | Google's coding assistant and command-line agent | Free options for individuals have been offered |
| Windsurf | AI code editor | A free tier with limits |
| Continue and similar | Open-source extensions for VS Code and JetBrains | The extension is free, but you may pay for the model it uses |

Claude Code is not on this list because it needs a paid plan or API credits. See [Claude Code for beginners](/blog/claude-code-for-beginners).

## For VS Code and other editors

- **VS Code:** Copilot, Gemini Code Assist and Continue have extensions.
- **JetBrains editors (such as IntelliJ):** Copilot has a plugin, and JetBrains offers its own AI features.
- **A whole AI editor:** [Cursor](/blog/cursor-ai-for-beginners) or Windsurf replace your editor.

## How to choose

1. What editor do you use? Pick a tool that works there.
2. Do you want suggestions only, or an agent that edits files? See [what AI coding agents are](/blog/what-are-ai-coding-agents).
3. What are the limits on the free plan?
4. What happens to your code? Read the privacy terms before using it on private or work projects.

## Free tool tips

- Free usage can run out on large tasks, so work in small steps.
- Do not paste secrets such as passwords or API keys.
- Read what it writes. Free does not mean correct.
- Compare two tools on the same task, not on reputation.

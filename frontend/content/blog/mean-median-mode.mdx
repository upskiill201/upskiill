Three ways to say "typical", and they can disagree.

## Direct answer

The mean is the sum divided by the count. The median is the middle value when sorted. The mode is the most frequent value. Use the median when data has outliers, because the mean gets pulled toward extreme values.

## Example

Values: 2, 3, 3, 4, 100

- Mean = 112 ÷ 5 = 22.4
- Median = 3
- Mode = 3

The 100 pulls the mean up. The median stays near the typical value.

## In Python

```python
import statistics as st

data = [2, 3, 3, 4, 100]
print(st.mean(data), st.median(data), st.mode(data))
```

## Which to use

| Situation | Use |
| :--- | :--- |
| Symmetric data | mean |
| Skewed or outliers | median |
| Categories | mode |

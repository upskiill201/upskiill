Events are how web pages react to people.

## Direct answer

Use `element.addEventListener(type, handler)` to run a function when an event happens. Common types are `click`, `input`, `submit`, `keydown` and `mouseover`. The handler receives an event object with details such as the target element.

## Basic example

```html
<button id="btn">Click me</button>
<script>
  const btn = document.querySelector("#btn");
  btn.addEventListener("click", () => {
    alert("Clicked!");
  });
</script>
```

## The event object

```javascript
input.addEventListener("input", (event) => {
  console.log(event.target.value);
});
```

## Removing listeners

```javascript
function onClick() { console.log("hi"); }
btn.addEventListener("click", onClick);
btn.removeEventListener("click", onClick);
```

You must pass the same function reference, so avoid anonymous functions if you need to remove it.

## Handy options

```javascript
btn.addEventListener("click", onClick, { once: true });
```

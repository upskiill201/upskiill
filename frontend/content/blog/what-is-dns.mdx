DNS is the internet's phone book.

## Direct answer

DNS (Domain Name System) translates domain names into IP addresses. You manage it with DNS records at your domain registrar or DNS provider. The main records are A (to an IP address), CNAME (alias to another name), MX (email) and TXT (verification and email security).

## Common record types

| Record | Purpose | Example |
| :--- | :--- | :--- |
| A | points a name to an IPv4 address | `example.com → 203.0.113.10` |
| AAAA | points to an IPv6 address | |
| CNAME | alias to another name | `www → example.com` |
| MX | where email goes | |
| TXT | verification, SPF, DKIM | |

## How a visit works

1. You type a domain in your browser.
2. Your device asks a DNS resolver for the address.
3. The resolver finds the records.
4. Your browser connects to that address.

## Propagation

DNS answers are cached. After a change, some people see the old answer until the cache expires, set by the TTL value.

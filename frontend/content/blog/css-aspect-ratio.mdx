Layouts jump when images load late. `aspect-ratio` reserves the space.

## Direct answer

The `aspect-ratio` property sets the ratio of an element's width to its height, such as `16 / 9`. It keeps boxes proportional as they scale and reserves space for images and embeds so the layout does not shift.

## Examples

```css
.video {
  width: 100%;
  aspect-ratio: 16 / 9;
}

.avatar {
  width: 64px;
  aspect-ratio: 1;
  border-radius: 50%;
  object-fit: cover;
}

img {
  max-width: 100%;
  height: auto;
}
```

```html
<iframe class="video" src="https://www.youtube.com/embed/xyz" title="Video"></iframe>
```

## Tips

- Combine with `object-fit: cover` for photos.
- Also set `width` and `height` attributes on images.

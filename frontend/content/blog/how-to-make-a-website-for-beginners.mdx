A website is just files on the internet. Here is how to make one, with or without coding.

## Direct answer

To make a website: decide what it's for, sketch the pages, build it (with a website builder, or with HTML and CSS if you want control), check it on a phone, and publish it. Start with one page that does one job well, then add more.

## Step by step

### 1. Decide the purpose
Portfolio, business, blog, event? One clear goal keeps it simple.

### 2. Sketch the pages
Most beginner sites need: Home, About, Contact, and one page for what you offer.

### 3. Choose how to build it

| | Website builder | Hand-coded (HTML & CSS) |
| :--- | :--- | :--- |
| Speed | Fast | Slower to start |
| Control | Limited by the builder | Full |
| Cost | Free tier, paid upgrades | Free to build, hosting may be free |
| Learning | Little | A valuable skill |

### 4. Write your content
Short, clear text and a few good photos. Write for a visitor in a hurry.

### 5. Build it
With a builder, pick a template. With code, start with [an HTML page](/blog/html-tutorial-for-beginners) and style it with [CSS](/blog/css-tutorial-for-beginners).

### 6. Make it work on phones
See [what is responsive web design](/blog/what-is-responsive-web-design).

### 7. Check the basics
- Titles on each page
- Alt text on images
- Contact details that work
- Spelling

### 8. Publish
See [how to launch a website](/blog/how-to-launch-a-website).

## Mistakes

- Too many pages at the start
- Huge images that load slowly
- Tiny text on phones
- No clear way to contact you

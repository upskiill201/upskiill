Interest is cheap. Money is evidence.

## Direct answer

Pre-selling means taking orders or deposits before building the full product, to test real demand. Be transparent about timing and refunds, set a goal and use the results to decide whether to build.

## How to run one

1. Create a landing page with a clear offer.
2. Set a price and a delivery timeline.
3. Promote to your target audience.
4. Aim for a set number of buyers.
5. If you reach it, build. If not, learn why.

## Be honest

State what is delivered, when and what happens if you cannot deliver.

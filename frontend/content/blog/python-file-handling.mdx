Files let your programs remember things.

## Direct answer

In Python, use `open()` inside a `with` block to read or write files. Use mode `"r"` to read, `"w"` to write and overwrite, and `"a"` to append. The `with` block closes the file automatically.

## Read a file

```python
with open("notes.txt", "r") as f:
    text = f.read()
print(text)
```

Read line by line:

```python
with open("notes.txt") as f:
    for line in f:
        print(line.strip())
```

## Write a file

```python
with open("out.txt", "w") as f:
    f.write("Hello\n")
```

Use `"a"` to add to the end instead of overwriting.

## File modes

| Mode | Meaning |
| :--- | :--- |
| `r` | read (default) |
| `w` | write, overwrites |
| `a` | append |
| `r+` | read and write |

## Handle missing files

```python
try:
    with open("data.txt") as f:
        print(f.read())
except FileNotFoundError:
    print("File not found")
```

Apps need somewhere to keep data and a way to know who is signed in.

## Direct answer

Supabase is a backend platform built on a Postgres database. It provides tables, user authentication, file storage and automatically generated APIs, so front-end apps can store data without a custom server. Turn on row level security so users can only access the data they should.

## What you get

- A hosted relational database.
- Sign-in with email and other providers.
- File storage.
- APIs and client libraries.

## Basic idea

1. Create a project.
2. Design tables.
3. Turn on **row level security** and write policies.
4. Use the public key in the browser and keep any service key secret on the server.
5. Connect your app.

## A simple policy idea

Allow a user to read and write only rows where the row's `user_id` equals their own ID.

## Cautions

- Never expose the service role key in front-end code.
- Test policies with two different users.

Chat is fast, which makes it easy to be unclear.

## Direct answer

Write chat messages that can be answered without a back-and-forth: include context, your question or request and any deadline. Use threads, mention people only when needed and respect working hours and time zones.

## Do this

- "Hi Sam, could you review the draft in the shared folder by 3pm? I need to send it to the client at 4."

## Not this

- "Hi" and then waiting.
- "Quick question?" with no question.

## Good habits

1. Use threads.
2. Use channels, not DMs, for shared information.
3. Mention only the people who need to act.
4. Avoid long messages. Move complex topics to a call or document.
5. Be kind in tone, since text lacks voice.

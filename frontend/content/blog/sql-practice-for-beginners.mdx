Reading about SQL doesn't make you good at it. Typing queries does.

## Direct answer

To practise SQL, write queries every day on a database that interests you. Use an in-browser SQL playground or an interactive course, try a SQL game for fun, and finish with a small project where you ask real questions of real data. Predict the result before you run each query.

## Exercise ladder

1. **Select and filter:** list all customers from one city.
2. **Sort:** top 5 most expensive items.
3. **Count and group:** orders per customer.
4. **Join:** customers with their orders.
5. **Change data:** add a record, update a price. Use `WHERE`!
6. **Design:** plan two tables and connect them.

## Games and interactive tools

Playing helps motivation. See our list of [SQL games](/blog/sql-games). Choose ones where you write real queries, not only click.

## Project ideas

- **Your budget:** where does the money go each month?
- **A film or music collection:** which year has the most? 
- **A tiny shop:** best-selling products, quietest days.
- **A cinema:** which shows fill up, who books most? (That's the dataset in Teyro's SQL course.)

Write five questions, then answer each with a query.

## Habits that make practice stick

- Practise a little every day.
- Predict the output first.
- Fix errors by reading the message.
- Keep a file of queries you're proud of.

Arrow functions make small functions neat.

## Direct answer

An arrow function is a compact way to write a function using `=>`. If the body is a single expression, the result is returned automatically. Arrow functions do not have their own `this`, which is useful in callbacks but wrong for object methods that rely on `this`.

## Syntax

```javascript
// regular
function add(a, b) {
  return a + b;
}

// arrow
const add = (a, b) => a + b;

// one parameter
const double = n => n * 2;

// multiple lines
const greet = (name) => {
  const message = "Hi " + name;
  return message;
};
```

## Great in callbacks

```javascript
const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);
```

## When not to use them

- Object methods that need `this`.
- Constructors (`new` will fail).
- Functions that need `arguments`.

## Direct answer

To deploy an AI-built app, export or sync the code to a Git repository, connect it to a host such as Vercel or Netlify, add environment variables for secrets and API keys, run the build and test the live site. Add a custom domain and monitoring when ready.

## Steps

1. **Save the code in Git** with a clear history.
2. **Run it locally** to confirm it builds.
3. **Choose a host** that suits your framework.
4. **Add environment variables** in the host's settings.
5. **Deploy** and read the logs.
6. **Test the live site** on desktop and phone.
7. **Add a domain** and HTTPS.
8. **Monitor errors** and usage.

## Common problems

| Problem | Likely fix |
| :--- | :--- |
| Build fails | read the log, check Node version and scripts |
| Blank page | check console errors and environment variables |
| Cannot connect to database | verify keys and allowed origins |

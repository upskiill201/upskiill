Every extra word is a small tax on the reader.

## Direct answer

Write concisely by cutting filler words and phrases, replacing long phrases with short ones, using active voice, removing repetition and using lists for steps. Check that each sentence earns its place.

## Replacements

| Wordy | Concise |
| :--- | :--- |
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| a large number of | many |
| has the ability to | can |
| in the event that | if |

## 15 tips (short list)

1. Cut introductions.
2. Delete "very" and "really".
3. Prefer verbs to noun phrases.
4. Use active voice.
5. Merge repeated sentences.
6. Use bullets for lists.
7. Limit sentences to one idea.
8. Remove "I think" where you are sure.
9. Replace jargon.
10. Use numbers.
11. Cut qualifiers.
12. Remove redundant pairs ("each and every").
13. Start with the point.
14. Delete the last sentence if it repeats.
15. Read aloud.

Quality depends on how you ask and how you check.

## Direct answer

AI-generated code quality ranges from excellent to flawed. Improve it by giving clear requirements, sharing your project's conventions, asking for tests and error handling, and reviewing and refactoring the result. Good code is readable, tested, consistent and does what you intended.

## What good looks like

- Clear names and small functions.
- Consistent with the rest of the project.
- Handles errors and edge cases.
- Covered by tests.
- No unnecessary dependencies.

## Prompts that raise quality

- "Follow the existing style in `src/utils`."
- "Add unit tests for edge cases."
- "Keep the solution simple. Do not add new libraries."
- "Explain trade-offs before changing anything."

## Red flags

- Large changes for a small request.
- Unused code and imports.
- Copy-pasted blocks.
- Tests that assert nothing.

## The Complete Photoshop Course Syllabus (Module-by-Module)

Whether taking an online course or local training, a comprehensive Photoshop syllabus must cover these six core modules:

```
[The 6-Module Photoshop Professional Syllabus]
                       │
  ┌────────────────────┼────────────────────┐
  │                    │                    │
  ▼                    ▼                    ▼
[Module 1: Foundations] [Module 2: Selections] [Module 3: Retouching]
  • Interface & Workspaces • Quick Select & Lasso • Healing Brush & Patch
  • Layer Masks & Clipping • Pen Tool Mastery     • Frequency Separation
  • Smart Objects (Vector) • Refine Edge / Hair   • Dodge & Burn Lighting
  │                    │                    │
  ▼                    ▼                    ▼
[Module 4: Color & Tone][Module 5: Typography] [Module 6: Compositions]
  • Curves & Levels LUTs   • Kerning & Hierarchy  • Complex Photobashing
  • Blend Modes (Screen)   • Vector Shapes        • Smart Filters & Export
  • Camera RAW Filter      • Poster & Ad Layout   • Web & Social Sizing
```

### Module 1: Non-Destructive Editing & Smart Objects
Never edit raw pixel layers directly. Master **Layer Masks** (black conceals, white reveals) and **Smart Objects** so you can resize, filter, and modify assets infinitely without quality degradation.

### Module 2: The Pen Tool and Precise Masking
The Pen Tool ($P$) is the gold standard for creating razor-sharp vector selections, isolating complex product silhouettes, and masking flyaway hair for commercial e-commerce photos.

### Module 3: Commercial Skin Retouching
Learn **Frequency Separation**—splitting an image into two layers: a Low-Frequency layer (color and tone) and a High-Frequency layer (fine skin pores and texture). This allows you to remove blemishes without creating a fake, plastic blur.

## Graphic Design vs UI/UX Design: Which Path Pays More?

Understanding the difference in daily work and compensation:

```
┌───────────────────────────────────────┬───────────────────────────────────────┐
│         GRAPHIC DESIGN                │            UI/UX DESIGN               │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • Focus: Visual aesthetics & branding │ • Focus: Usability, user psychology   │
│ • Deliverables: Logos, banners, ads   │ • Deliverables: Wireframes, Figma apps│
│ • Tools: Photoshop, Illustrator       │ • Tools: Figma, FigJam, Maze, Jira    │
│ • Metric: Brand appeal & beauty       │ • Metric: Conversion rate & usability │
│ • Avg Salary: $50,000 – $70,000/yr    │ • Avg Salary: $85,000 – $130,000/yr   │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

While graphic design focuses on what a brand *looks* like, UI/UX design solves how a digital product *works*. UI/UX designers command significantly higher salaries due to their direct impact on software usability, onboarding conversion, and retention.

If you want to transition from static graphic design to high-income product design, follow this standard industry framework:

```
[User Problem / Product Goal]
              │
              ▼
[Step 1: UX Research & Empathy] ───> User interviews, personas & journey maps
              │
              ▼
[Step 2: Information Architecture] > Wireframes & low-fidelity user flows
              │
              ▼
[Step 3: UI Design Systems]     ───> Color tokens, 8px grid & typography scale
              │
              ▼
[Step 4: Interactive Prototype] ───> Figma component states, micro-animations
              │
              ▼
[Step 5: Usability Testing]     ───> User task completion tests & developer handoff
```

### 1. The 8pt Spatial Grid System
Professional UI design aligns every padding, margin, and icon to multiples of 8 ($8\text{px}, 16\text{px}, 24\text{px}, 32\text{px}, 48\text{px}$). This guarantees visual consistency and makes developer handoff seamless.

### 2. Design Tokens and Components
Build modular, reusable button variants, input fields, and modal cards using **Figma Auto Layout** and component variants.

A free, simple way to put your first site online.

## Direct answer

To host a site on GitHub Pages, create a repository, add an `index.html` file, go to **Settings → Pages**, choose the branch to publish and save. GitHub gives you a public address. You can add a custom domain later.

## Steps

1. **Create a GitHub account** and a new public repository.
2. **Add `index.html`** and your CSS and images.
3. **Open Settings → Pages.**
4. **Choose the branch** (often `main`) and the root folder.
5. **Save.** Wait a minute, then visit the address shown.

## Minimal file

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My first site</title>
</head>
<body>
  <h1>Hello, world</h1>
</body>
</html>
```

## Update the site

Commit changes and push. Pages rebuilds automatically.

## Limits

Static files only, and public repositories for free plans. Check GitHub's current policies for size and traffic limits.

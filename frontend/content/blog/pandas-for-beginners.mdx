pandas turns messy files into answers.

## Direct answer

pandas is Python's main library for tabular data. Load a file with `pd.read_csv`, inspect it with `head`, `info` and `describe`, clean column names, fix types, remove duplicates, handle missing values and then group and summarise.

## A first workflow

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()
df.info()

df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")
df = df.drop_duplicates()
df["date"] = pd.to_datetime(df["date"])
df["revenue"] = df["revenue"].fillna(0)

summary = df.groupby("region")["revenue"].sum().sort_values(ascending=False)
print(summary)
```

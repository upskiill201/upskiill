ChatGPT is a chatbot that writes and explains in plain language. Getting good results is mostly about asking well.

## Direct answer

To use ChatGPT, sign in on its website or app, type what you want in plain language, add context and the format you need, read the reply and then refine it with follow-up messages. Treat the answer as a draft: check facts and numbers before relying on them.

## Getting started

1. Go to ChatGPT's official site or app and sign in.
2. Type a request.
3. Read the reply.
4. Ask for changes: "shorter", "friendlier", "as a table".

## The prompt recipe

| Part | Example |
| :--- | :--- |
| Role | "You are a friendly editor" |
| Task | "Shorten this email" |
| Context | "It's for a customer who is upset about a delay" |
| Format | "Under 100 words, three short paragraphs" |
| Example | "Keep a tone like this: ..." |

More examples in [ChatGPT prompts for beginners](/blog/chatgpt-prompts-for-beginners).

## 10 useful things to try

1. Rewrite an email in a friendlier tone
2. Summarise a long article
3. Explain a concept at your level
4. Create a weekly plan
5. Brainstorm names or ideas
6. Prepare interview questions. See [common interview questions](/blog/common-interview-questions-and-answers)
7. Turn notes into a checklist
8. Explain an Excel formula
9. Draft a polite message
10. Quiz you on a topic. See [ChatGPT for studying](/blog/chatgpt-for-studying)

## Free or paid

Plans and limits change. Start with the free version if available and upgrade only if you hit limits on tasks you do often.

## Mistakes

- Vague prompts
- Trusting the first answer
- Pasting private data
- Giving up after one poor reply. Follow up instead.

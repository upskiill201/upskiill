Learn before you build everything.

## Direct answer

A minimum viable product (MVP) is the simplest version of a product that solves a core problem for early users and lets you learn whether the idea works. Build only the features needed to test your biggest assumption, then collect feedback.

## MVP types

| Type | Description |
| :--- | :--- |
| Landing page | describe the idea and measure sign-ups |
| Concierge | deliver the service manually |
| Wizard of Oz | looks automated, done by hand |
| Single feature | one core function |

## How to scope one

1. Define the target customer and problem.
2. List your riskiest assumption.
3. Choose the smallest test.
4. Set a success measure.
5. Build, launch, learn.

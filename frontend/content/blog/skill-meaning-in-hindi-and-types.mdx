## Direct Answer: Skill Meaning in Hindi at a Glance

> **Skill (कौशल / हुनर)** किसी कार्य को सही तकनीक, अभ्यास और समझ के साथ कुशलतापूर्वक करने की क्षमता है। यह जन्मजात होने के बजाय निरंतर अभ्यास (Practice) और सीखने से हासिल की जाती है।

```
┌─────────────────────────────────────────────────────────────┐
│                    SKILLS CLASSIFICATION (कौशल के प्रकार)   │
├─────────────────────────────────────────────────────────────┤
│  1. HARD SKILLS (तकनीकी कौशल)  ──> Coding, SQL, Design      │
│  2. SOFT SKILLS (व्यवहार कौशल)  ──> Communication, Teamwork  │
│  3. LIFE SKILLS (जीवन कौशल)     ──> Stress & Money Management│
│  4. META-SKILLS (सीखने का कौशल) ──> Active Recall, Learning  │
└─────────────────────────────────────────────────────────────┘
```

| Skill Category | हिंदी में नाम | मुख्य उदाहरण (Examples) | करियर में उपयोग |
| :--- | :--- | :--- | :--- |
| **Hard Skills** | तकनीकी कौशल | Python, Web Development, Accounting, Graphic Design | किसी विशिष्ट काम को सटीकता से पूरा करना |
| **Soft Skills** | व्यावहारिक कौशल | Communication, Problem Solving, Leadership, Empathy | टीम के साथ मिलकर काम करना और इंटरव्यू जीतना |
| **Life Skills** | जीवन कौशल | Time Management, Budgeting, Emotional Resilience | दैनिक जीवन और तनाव को संतुलित रखना |
| **Meta-Skills** | सीखने का कौशल | Spaced Repetition, Active Recall, Speed Reading | किसी भी नए विषय को तेजी से सीखना |

## 1. Hard Skills और Soft Skills में क्या अंतर है?

### Hard Skills (तकनीकी कौशल)
यह वह कौशल हैं जिन्हें किताबों, पाठ्यक्रमों और प्रशिक्षण के माध्यम से सीखा जाता है और जिनका सटीक मूल्यांकन किया जा सकता है:
* **उदाहरण:** Python में कोड लिखना, Excel में फॉर्मूला लगाना, SQL डेटाबेस क्वेरी करना (देखें [SQL games for practice](/blog/sql-games) और [Duolingo for Python](/blog/duolingo-for-python))।

### Soft Skills (व्यक्तिगत व व्यवहार कौशल)
यह व्यक्ति के बात करने के तरीके, सोचने की क्षमता और दूसरों के साथ सामंजस्य बिठाने से संबंधित होते हैं:
* **उदाहरण:** टीमवर्क, प्रभावी बातचीत (Communication), और समय प्रबंधन (देखें [presentation skills guide](/blog/presentation-skills-guide))।

AI tools speed up good work and mistakes.

## Direct answer

The main risks are insecure generated code, secrets pasted into prompts or committed to repositories, invented or malicious packages, prompt injection from untrusted content and agents with more permissions than they need. Reduce them with review, scanning, least-privilege access and a sandbox.

## Risks and responses

| Risk | What to do |
| :--- | :--- |
| Insecure code | review, test, run security scanners |
| Leaked secrets | use environment variables, secret scanning |
| Fake or risky packages | verify dependencies before installing |
| Prompt injection | treat fetched content as untrusted, review actions |
| Over-permissioned agents | limit access, use read-only where possible |
| Data exposure | check your tool's data policy |

## Good habits

1. Never paste real secrets into prompts.
2. Require approval for commands that delete, deploy or send data.
3. Work on a branch, not directly on production.
4. Keep dependencies reviewed and pinned.
5. Follow your organisation's policies.

Plenty of C courses are free. A few checks help you choose one you'll finish.

## Direct answer

A good beginner C course covers variables, input and output, conditions, loops, functions, arrays, strings and pointers, and has you write and run code in every lesson. Many are free at least to start. Treat a certificate as a bonus: programs you've written matter more.

## What the course should cover

1. Setup and first program
2. Data types and operators
3. Conditions and loops
4. Functions
5. Arrays and strings
6. Pointers and memory
7. Structs and files

## What to check

| Question | Why |
| :--- | :--- |
| Do I write code in every lesson? | Reading isn't enough |
| Is feedback given when I'm wrong? | Speeds learning |
| Are lessons short? | Easier to finish |
| What's free? | Some only offer a first module |
| How long is it? | Plan your time |

## Duration

Many learners spend a few weeks on the basics and a few months to be comfortable. It depends on your schedule.

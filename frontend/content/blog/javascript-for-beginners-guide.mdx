JavaScript runs in every web browser, which is why it's one of the most useful first languages.

## Direct answer

To learn JavaScript from scratch: write tiny programs using variables, decisions, loops, functions, lists (arrays) and objects, then use JavaScript to change a web page. Practise every day in short sessions and build small projects. The basics take a few weeks; comfort takes a few months.

## A first program

```js
const name = "Sam";
let score = 3;

if (score > 2) {
  console.log(name + " is winning");
}
```

`const` and `let` store values, `if` makes a decision and `console.log` shows output.

## Learning order

1. Values and variables
2. Decisions with `if`
3. Loops
4. Functions
5. Arrays (lists)
6. Objects
7. The DOM: changing web pages. See [JavaScript DOM tutorial](/blog/javascript-dom-tutorial-for-beginners)
8. Events and forms
9. Fetching data

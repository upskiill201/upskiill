"Agent" is one of the most used words in AI right now. Here is what it means without the hype.

## Direct answer

An AI agent is a program built on an AI model that works toward a goal by planning steps, using tools such as search, files or code, checking the results and continuing until it finishes or gets stuck. Unlike a chatbot that only replies, an agent can take actions. People still need to set limits and review the outcome.

## The agent loop

1. **Goal:** "Find the three cheapest options and summarise them."
2. **Plan:** decide the next step.
3. **Act:** use a tool, such as a web search.
4. **Observe:** read the result.
5. **Repeat or finish.**

## Chatbot vs agent

| | Chatbot | Agent |
| :--- | :--- | :--- |
| Output | Replies in text | Actions plus a result |
| Tools | Usually none | Search, code, files, apps |
| Steps | One response | Many, in a loop |
| Risk | Wrong text | Wrong text and wrong actions |

## Examples

- **Coding agents** that edit files and run tests. See [what AI coding agents are](/blog/what-are-ai-coding-agents).
- **Support agents** that look up an order and draft a reply.
- **Research agents** that gather and summarise sources.

## Building one

1. Pick a narrow job.
2. Choose a model.
3. Give it a few safe tools.
4. Set limits on what it can do.
5. Test with cases where it should fail.

## Risks

- Taking wrong actions
- Leaking data through tools
- Being tricked by text on a web page
- Costs from long loops

Keep a human in the loop for anything important.

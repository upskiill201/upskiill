Two small operators that remove a lot of defensive code.

## Direct answer

Optional chaining (`?.`) safely reads a property or calls a function when a value may be `null` or `undefined`. Nullish coalescing (`??`) supplies a default only when the value is `null` or `undefined`. Together they handle missing data cleanly.

## Examples

```typescript
const city = user?.address?.city;
const length = items?.length ?? 0;
user?.sendMessage?.("Hello");

const count = 0;
console.log(count || 10); // 10, because 0 is falsy
console.log(count ?? 10); // 0, because 0 is not null
```

## When to use which

| Situation | Use |
| :--- | :--- |
| Might be missing | `?.` |
| Default only for null or undefined | `??` |
| Default for any falsy value | the or operator |

CSS makes web pages look good. This tutorial covers the ideas you need first, with short examples.

## Direct answer

CSS is a set of rules that style HTML. Each rule picks an element (a selector) and sets properties like colour, size and spacing. Learn selectors, the box model (margin, border, padding), then Flexbox and Grid for layout. Practise by styling a real page.

## How a CSS rule works

```css
h1 {
  color: #1f3a93;
  font-size: 2rem;
}
```

`h1` is the selector. Inside the braces are properties and values.

## Selectors

```css
p { line-height: 1.5; }          /* every paragraph */
.card { padding: 16px; }          /* anything with class="card" */
#intro { font-weight: bold; }     /* the element with id="intro" */
```

Classes are the ones you'll use most.

## The box model

Every element is a box:

- **Content**
- **Padding** inside the border
- **Border**
- **Margin** outside the border

```css
.card {
  padding: 16px;
  border: 1px solid #ddd;
  margin: 24px 0;
}
```

## Flexbox: a row or column

```css
.menu {
  display: flex;
  gap: 16px;
  justify-content: space-between;
}
```

Flexbox lines items up and spaces them. Perfect for menus and rows of cards.

## Grid: rows and columns

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

Grid makes three equal columns. Perfect for galleries.

## Direct Answer: What Is Coding?

Coding is the process of writing step-by-step instructions, called **code**, in a programming language such as Python or JavaScript, so a computer can perform a task. Code tells a computer what data to store, what decisions to make and what actions to repeat. Websites, apps, games, smart devices and AI systems are all built with code.

| Everyday Thing | What the Code Does | Common Language |
| :--- | :--- | :--- |
| **Calculator app** | Takes numbers, applies math, shows the result | Swift, Kotlin |
| **Login page** | Checks your password matches your account | JavaScript, Python |
| **Streaming recommendations** | Suggests shows based on what you watched | Python, Java |
| **Online shop checkout** | Adds prices, applies discounts, charges your card | JavaScript, Java |
| **Smart thermostat** | Turns heating on below a set temperature | C, C++ |
| **Spreadsheet formula** | Calculates totals automatically | Excel formulas (a kind of code) |
| **AI chatbot** | Processes your message and generates a reply | Python |

## Coding Explained With a Recipe

Think of a recipe for making tea:

1. Boil water.
2. Put a tea bag in a cup.
3. Pour water into the cup.
4. Wait 3 minutes.
5. If you like it sweet, add sugar.
6. Remove the tea bag.

A recipe is a set of precise instructions in order, including a **decision** (step 5). Code is the same idea, written in a language a computer can follow exactly. Here is the tea recipe as Python code:

```python
likes_sweet_tea = True

print("Boiling water...")
print("Adding tea bag to cup...")
print("Pouring water...")
print("Waiting 3 minutes...")

if likes_sweet_tea:
    print("Adding sugar...")

print("Removing tea bag. Your tea is ready!")
```

The difference between a recipe and code: a human cook can guess what you meant. A computer cannot. It does exactly what the code says, which is why precision matters in coding.

## 5 Simple Examples of Coding

### Example 1: Displaying a Message

The traditional first program in almost every language:

```python
print("Hello, world!")
```

This tells the computer to show the text `Hello, world!` on the screen.

### Example 2: Storing Information (Variables)

```python
name = "Amara"
streak_days = 12
print(name + " has a " + str(streak_days) + "-day streak!")
```

A **variable** is a named box that holds information. Here, one box holds a name and another holds a number.

### Example 3: Making a Decision (Conditionals)

```python
temperature = 16

if temperature < 18:
    print("Turn the heating on.")
else:
    print("Heating off.")
```

This is essentially the logic inside a smart thermostat.

### Example 4: Repeating an Action (Loops)

```python
for day in range(1, 8):
    print("Day " + str(day) + ": practise for 15 minutes")
```

A **loop** repeats instructions, here printing a 7-day practice plan without writing seven lines.

### Example 5: Reusable Instructions (Functions)

```python
def add_discount(price, percent):
    return price - (price * percent / 100)

print(add_discount(80, 25))   # 60.0
```

A **function** is a mini-program you can reuse. Online shops use functions like this every time you see a sale price.

Variables, conditionals, loops and functions are the four building blocks of almost all code. Learn these, and you can read a surprising amount of real-world code.

## Can I Learn Coding Without Any Knowledge?

Yes. Every developer started with zero knowledge. Here is what you do **not** need:

- A computer science degree
- Strong math skills (see [do you need math for coding?](/blog/do-you-need-math-for-coding))
- An expensive computer
- To have started as a child
- A "tech brain"

Here is what you **do** need:

- **Curiosity** about how things work
- **15 to 30 minutes a day**, consistently
- **Patience** with confusion in the first few weeks
- **Willingness to type code yourself**, not just watch

Beginners who succeed usually are not the smartest people in the room. They are the ones who practise a little every day and do not quit when their code breaks.

## Write Your First Code in 10 Minutes

You do not need to install anything to try it:

1. Open any free online Python editor in your browser (search "online Python editor").
2. Delete anything in the editor and type:

```python
name = input("What is your name? ")
print("Welcome to coding, " + name + "!")
```

3. Press **Run**.
4. Type your name when asked.

You have just written a program that takes input, stores it in a variable and prints a personalised message. That is real coding.

Scroll down to row 400 of a busy spreadsheet and you are working blind: which column held the invoice totals, which one held the due dates, nobody knows. The fix takes ten seconds and is one of the highest-value tricks in Excel. **To pin the top row in Excel, go to the View tab, open the Freeze Panes dropdown, and choose Freeze Top Row.** The row locks in place while everything beneath it scrolls normally. Excel calls this *freezing*; most people say *pinning* — same feature, same result.

Here is the full toolkit: pinning several rows, pinning columns, doing both at once, what to do when the option is greyed out, and how to make headers repeat on printed pages too.

## Pin the Top Row in Three Steps

1. Click any cell in your worksheet — location does not matter for this variant.
2. Open the **View** tab on the ribbon.
3. Click **Freeze Panes**, then **Freeze Top Row**.

A thin solid line appears under row 1. Scroll anywhere in the sheet — row 1 stays put. To undo it later, return to the same dropdown and pick **Unfreeze Panes**.

Prefer the keyboard? Press **Alt, then W, then F, then F** on Windows desktop Excel to toggle freezing without touching the mouse.

## Pinning Anything Else: Multiple Rows, Columns, or Both

The **Freeze Top Row** button only handles row 1. For everything else you use the general-purpose option, which freezes *everything above and left of the cell you selected* before opening the menu:

| You want pinned | Select this first | Then click |
| --- | --- | --- |
| Top row only | Any cell | Freeze Top Row |
| First column only | Any cell | Freeze First Column |
| Rows 1-3 | Cell A4 (or row 4) | Freeze Panes |
| Rows 1-2 plus column A | Cell B3 | Freeze Panes |
| Row 1 plus columns A-B | Cell C2 | Freeze Panes |

### Pin Several Rows

Say rows 1 through 3 hold a merged title, a date range and your real column headers:

1. Select row 4 — click its row number, or just click cell A4.
2. View tab, Freeze Panes dropdown, **Freeze Panes**.

All three rows above stay visible. The rule to remember: **select where scrolling should start, not what should stay still.**

### Pin Rows and Columns Together

Selecting cell B3 before freezing locks rows 1-2 *and* column A simultaneously — anything above and left of B3 goes rigid. This is the setup for wide ledgers where both the header row and the account-name column need to survive diagonal scrolling.

## When Freeze Panes Refuses to Work

If the option is greyed out or does nothing, check these in order:

- **You are in Page Layout or Page Break Preview.** Freezing only works in **Normal** view — switch it on the View tab.
- **A cell is in edit mode.** If the cursor blinks inside a cell, press Escape first.
- **The sheet is protected or shared.** Remove protection via Review, Unprotect Sheet (password may be required).
- **You expected the frozen line to appear somewhere else.** The line lands above and left of whatever cell was active — reselect, unfreeze, refreeze.

## Printing Is a Different Setting Entirely

Frozen headers exist only on screen; printed pages will not repeat them. For paper output:

1. Go to the **Page Layout** tab and click **Print Titles**.
2. In *Rows to repeat at top*, select your header row, for example 1:1.
3. Print preview now shows those headers atop every page.

| Tool | What it controls | Where |
| --- | --- | --- |
| Freeze Panes | On-screen visibility while scrolling | View tab |
| Split bars | Two independently scrollable views of one sheet | View tab |
| Print Titles | Header repetition on printed pages | Page Layout tab |

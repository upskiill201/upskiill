## Direct answer

A Jupyter Notebook is a document made of cells. Code cells run Python and show results below, while text cells hold explanations. It is the standard tool for exploring data and sharing analysis. Install with pip, start it from the terminal and run cells with Shift+Enter.

## Install and start

```bash
pip install notebook
jupyter notebook
```

## Using it

- **Shift+Enter** runs a cell.
- **Markdown cells** hold headings and notes.
- **Output** appears under each code cell, including charts.

## Good habits

1. Restart and run all before sharing to check it works top to bottom.
2. Keep cells small and focused.
3. Give the notebook a clear title and sections.
4. Do not store passwords or keys in notebooks.

## Alternatives

JupyterLab, hosted notebooks and editors with notebook support.

Writing the app is half the job. Releasing it is the other half.

## Direct answer

To publish a React Native app, create Apple and Google developer accounts, prepare icons, screenshots and a privacy policy, make signed production builds, test them through TestFlight or Google Play testing tracks, then submit for review. Plan time for feedback.

## Checklist

1. **Accounts:** Apple Developer Program and Google Play Console. Both have fees and verification steps. Check current requirements.
2. **App identity:** name, bundle ID or package name, version number.
3. **Assets:** icon, splash screen and screenshots.
4. **Policies:** privacy policy, data safety and age rating answers.
5. **Builds:** create production builds (for Expo projects, EAS Build helps).
6. **Testing:** TestFlight and Play testing tracks with real users.
7. **Submit** and respond to review notes.
8. **Release** and monitor crashes.

## After launch

Use over-the-air updates for small JavaScript fixes where allowed by store rules, and submit new builds for native changes.

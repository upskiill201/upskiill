The best way to use an AI assistant is as a partner, not a vending machine.

## Direct answer

AI pair programming means working alongside an assistant that suggests, explains and writes code while you steer. You set the goals, give context and review the results. Use it to explore options, learn unfamiliar code and speed up routine work, while keeping responsibility for decisions.

## Habits that work

1. **State the goal and constraints** before asking for code.
2. **Work in small steps** and check each.
3. **Ask why,** not only what: "Explain this function".
4. **Ask for alternatives** and trade-offs.
5. **Read the code** before running it.
6. **Write some code yourself** to keep skills sharp.

## Good uses

- Explaining unfamiliar code.
- Generating boilerplate.
- Writing tests.
- Suggesting refactors.
- Rubber-duck debugging.

## Risks

- Accepting plausible but wrong code.
- Losing understanding of your own project.

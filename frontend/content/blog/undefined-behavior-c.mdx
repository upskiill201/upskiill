In C, some mistakes do not give an error. They give no promises.

## Direct answer

Undefined behavior (UB) occurs when your code does something the C standard does not define, so anything can happen. It may work on your machine and fail on another. Avoid it by initialising variables, staying in bounds, checking pointers and testing with sanitizers.

## Common examples

```c
int x;
printf("%d\n", x);     // uninitialised

int a = 2147483647;
a = a + 1;             // signed overflow

int arr[3];
arr[3] = 1;            // out of bounds

int *p = NULL;
*p = 1;                // null dereference
```

## How to find it

```bash
gcc -Wall -Wextra -g -fsanitize=address,undefined main.c -o app
./app
```

## Habits that help

1. Initialise everything.
2. Check array indexes.
3. Check pointers.
4. Compile with warnings and sanitizers.

Enums give names to related values.

## Direct answer

An enum is a named group of constants. Numeric enums assign numbers starting at 0, and string enums assign text. Enums produce real JavaScript code. Many developers prefer union types of string literals for simplicity.

## Examples

```typescript
enum Status {
  Active = "ACTIVE",
  Inactive = "INACTIVE",
}

function setStatus(s: Status) {}
setStatus(Status.Active);
```

## The union alternative

```typescript
type Status = "active" | "inactive";
function setStatus(s: Status) {}
setStatus("active");
```

## Const object alternative

```typescript
const Status = { Active: "active", Inactive: "inactive" } as const;
type StatusType = typeof Status[keyof typeof Status];
```

## Which to choose

- Union types for most cases.
- Enums when you want a named object with values at runtime and your team prefers them.

HTML and CSS are the two languages every web page is built from. They are a gentle first step into coding, because you can see every change straight away.

## Direct answer

Learn HTML first (the structure of a page: headings, paragraphs, links, images), then CSS (colours, fonts, spacing and layout). Build a small real page in your first week, then add one new idea at a time. Most beginners can make a decent simple page within days and feel comfortable in a few weeks of regular practice.

## What each does

| | HTML | CSS |
| :--- | :--- | :--- |
| Job | Structure and content | Appearance and layout |
| Examples | Headings, links, images, lists | Colours, fonts, spacing, columns |
| Like | The skeleton of a house | The paint and furniture |

## A step-by-step path

1. **Your first page:** a heading, a paragraph and a link.
2. **More HTML:** lists, images, sections.
3. **CSS basics:** colour, fonts, spacing.
4. **The box model:** margins, padding, borders.
5. **Layout:** Flexbox and Grid. See [CSS tutorial for beginners](/blog/css-tutorial-for-beginners).
6. **Responsive design:** pages that work on phones and laptops. See [what is responsive web design](/blog/what-is-responsive-web-design).
7. **Publish:** put your page on the internet for free. See [how to launch a website](/blog/how-to-launch-a-website).

## How long does it take?

It depends on your time. A simple page can take an afternoon. Comfortable with layout can take weeks of short daily practice. Short regular sessions beat long rare ones.

## Project ideas

- A page about yourself
- A one-page menu for a real or imaginary cafe
- A small portfolio with three projects
- A birthday invitation page
- A tribute page for a hobby

## Tips

- Type the code yourself. Don't only copy.
- Change one thing at a time and watch what happens.
- Use your browser's inspect tool to see how other sites are built.
- Build projects, not only exercises.

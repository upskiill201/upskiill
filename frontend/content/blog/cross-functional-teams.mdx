Great outcomes need many skills. So do great teams.

## Direct answer

A cross-functional team combines people from different functions to deliver a shared goal. To lead one, agree a clear goal and success measures, define roles and decisions, set a regular communication rhythm and make sure each member's manager understands the commitment.

## How to start

1. **Clarify the goal** and why it matters to each function.
2. **Define roles** with a simple [RACI matrix](/blog/raci-matrix-explained).
3. **Agree how decisions are made.**
4. **Set a rhythm:** short weekly check-ins.
5. **Share progress** visibly.
6. **Respect each function's constraints.**

## Common problems

| Problem | Fix |
| :--- | :--- |
| Competing priorities | involve managers early |
| Jargon gaps | use plain language |
| Unclear ownership | name one owner per deliverable |

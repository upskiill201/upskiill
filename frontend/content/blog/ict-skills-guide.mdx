## 1. Operating Systems and File Management

A fundamental ICT skill is understanding how operating systems organize digital assets:

* **File Hierarchy:** Creating nested directories (`Projects/2026/Q3_Audit/`).
* **Essential Shortcut Keys:** `Ctrl+C` (Copy), `Ctrl+V` (Paste), `Ctrl+Z` (Undo), `Ctrl+F` (Find). Learn more in [how to learn basic computer skills](/blog/how-to-learn-basic-computer-skills).
* **Storage Maintenance:** Performing disk cleanups, clearing browser caches, and updating antivirus signatures.

## 3. Cyber Hygiene and Online Safety

* **Phishing Detection:** Inspecting email header domains before clicking attachment links.
* **Password Management:** Creating 16-character alphanumeric passphrases.
* **Data Encryption Basics:** Understanding HTTPS, SSL certificates, and secure cloud backups (see [Security+ certification prep](/blog/security-plus-certification)).

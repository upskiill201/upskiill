Setting up native tooling used to be the hardest part of React Native. Expo takes that away.

## Direct answer

Expo is a framework and set of services for building React Native apps. It handles project setup, a development server, common device features and building for the app stores. You can start with one command and preview your app on a real phone with Expo Go.

## Start a project

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

Scan the QR code with Expo Go on your phone, or press a key to open a simulator.

## What Expo gives you

- File-based routing with Expo Router.
- Libraries for camera, location, notifications and more.
- Tools to build and submit apps.
- Over-the-air updates for JavaScript changes.

## When to go beyond Expo Go

If you need custom native code, create a development build. Expo supports this without abandoning the workflow.

A playground with real data.

## Direct answer

Kaggle is a platform for data science learning. You can find datasets, run notebooks in the browser, read other people's solutions and join competitions. Start with a beginner dataset and a public notebook, then try your own analysis.

## How to start

1. **Create an account.**
2. **Explore datasets** and pick a small, clean one.
3. **Open a public notebook** and run it.
4. **Change something** and see what happens.
5. **Write your own notebook** with clear explanations.
6. **Try a beginner competition** when ready.

## Benefits

- Free practice data and compute.
- Examples to learn from.
- A portfolio of notebooks.

## Tips

- Explain your reasoning in text.
- Do not just copy top solutions.
- Check dataset licences.

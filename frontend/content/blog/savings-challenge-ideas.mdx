Saving feels easier when it is a game. These challenges turn a goal into a routine.

## Direct answer

A savings challenge sets a simple rule for putting money aside, such as saving a rising amount each week. Popular versions include the 52-week challenge, round-ups, a no-spend week and saving every note of a certain value. Pick one you can maintain and automate it if you can.

## Six challenges

1. **52-week challenge:** save 1 in week one, 2 in week two and so on. The total over 52 weeks is 1,378.
2. **Reverse 52-week:** start with the biggest amount when motivation is high and finish small.
3. **Round-up challenge:** round each purchase up to the next whole unit and save the difference.
4. **Save a specific note:** every time you get a particular note, set it aside.
5. **No-spend week:** one week a month, spend only on essentials.
6. **Per-payday percentage:** move a fixed percentage each payday.

## How to choose

Check your budget first. If a challenge asks for more than you can spare in some weeks, you will quit. A smaller, steady one beats an ambitious one you abandon.

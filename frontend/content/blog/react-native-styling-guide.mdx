Styling feels like CSS, with a few differences.

## Direct answer

React Native styles are JavaScript objects passed to the `style` prop, usually created with `StyleSheet.create`. Layout uses Flexbox, and the default direction is column. Property names use camelCase, such as `backgroundColor`.

## Example

```jsx
import { View, Text, StyleSheet } from "react-native";

export default function Card() {
  return (
    <View style={styles.card}>
      <Text style={styles.title}>Hello</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    flexDirection: "row",
    alignItems: "center",
    justifyContent: "space-between",
    padding: 16,
    borderRadius: 12,
    backgroundColor: "#fff",
  },
  title: { fontSize: 18, fontWeight: "600" },
});
```

## Differences from CSS

| CSS | React Native |
| :--- | :--- |
| `background-color` | `backgroundColor` |
| default row | default column |
| no units | numbers are density-independent pixels |
| cascade | no inheritance except some text styles |

## Platform differences

```jsx
import { Platform } from "react-native";
const shadow = Platform.select({
  ios: { shadowOpacity: 0.2, shadowRadius: 6 },
  android: { elevation: 4 },
});
```

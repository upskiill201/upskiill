Your site has to live somewhere.

## Direct answer

Web hosting stores your site's files on a server and delivers them to visitors. Beginners can choose static hosting for HTML, CSS and JavaScript sites, shared or managed hosting for WordPress and a VPS when they need more control. Compare price, speed, support and limits.

## Types of hosting

| Type | Good for | Notes |
| :--- | :--- | :--- |
| Static hosting | HTML, CSS, JS sites | simple, often free tiers |
| Shared hosting | small WordPress sites | cheap, shared resources |
| Managed hosting | WordPress and apps | support included |
| VPS | custom setups | needs technical skills |
| Cloud platforms | apps with backends | flexible, more to learn |

## What to compare

- Price now and at renewal.
- Speed and uptime history.
- Backups and security.
- Support and documentation.
- Limits on traffic and storage.

## For a first site

Start with static hosting, such as GitHub Pages, Netlify or Vercel. You can always move later.

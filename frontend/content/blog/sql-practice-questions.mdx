You learn SQL by writing it. Try these before you read the answers.

## Sample tables

```text
customers(id, name, city)
orders(id, customer_id, total, created_at)
```

## Questions

1. List all customers.
2. List customers from "Lagos".
3. List the 5 largest orders.
4. Count how many orders exist.
5. Show total revenue.
6. Show revenue per customer.
7. Show customers with more than 3 orders.
8. List customers with their order totals.
9. Find customers who have no orders.
10. Find the average order total.

## Answers

```sql
-- 1
SELECT * FROM customers;
-- 2
SELECT * FROM customers WHERE city = 'Lagos';
-- 3
SELECT * FROM orders ORDER BY total DESC LIMIT 5;
-- 4
SELECT COUNT(*) FROM orders;
-- 5
SELECT SUM(total) FROM orders;
-- 6
SELECT customer_id, SUM(total) FROM orders GROUP BY customer_id;
-- 7
SELECT customer_id FROM orders GROUP BY customer_id HAVING COUNT(*) > 3;
-- 8
SELECT c.name, o.total FROM customers c JOIN orders o ON o.customer_id = c.id;
-- 9
SELECT c.name FROM customers c LEFT JOIN orders o ON o.customer_id = c.id WHERE o.id IS NULL;
-- 10
SELECT AVG(total) FROM orders;
```

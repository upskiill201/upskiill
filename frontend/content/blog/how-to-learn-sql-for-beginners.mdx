SQL is the language for asking databases questions. It is readable, and you can be useful with a small part of it.

## Direct answer

To learn SQL, work through these in order: reading data with `SELECT`, filtering with `WHERE`, sorting and limiting, counting and grouping, joining tables, then adding, updating and deleting data safely. Practise on a real database every day. A few weeks of short daily sessions gets most beginners to confident basics.

## Your first query

```sql
SELECT name, price
FROM tickets
WHERE price < 10
ORDER BY price;
```

It asks for the name and price of tickets under 10, cheapest first.

## The learning path

1. **SELECT and FROM:** pick columns and a table.
2. **WHERE:** filter rows.
3. **ORDER BY and LIMIT:** sort and cut.
4. **COUNT, SUM, AVG, GROUP BY:** summarise.
5. **JOINs:** combine tables.
6. **INSERT, UPDATE, DELETE:** change data carefully.
7. **Designing tables:** keys, relationships.

## How long does it take?

| Goal | Rough time with regular practice |
| :--- | :--- |
| Read simple data | Days |
| Confident with joins and grouping | A few weeks |
| Comfortable at work | Months of real use |

## Practise well

- Use a real, interesting dataset.
- Type queries; don't just read them.
- Predict the result before you run.
- Break things in a safe copy.

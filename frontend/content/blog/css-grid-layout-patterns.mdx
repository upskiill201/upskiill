Five patterns cover most pages.

## Direct answer

The most useful CSS Grid layouts are the page layout with named areas, auto-fitting card grids, sidebar layouts, equal-height columns and centred content. Each takes only a few lines.

## 1. Page layout

```css
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 240px 1fr;
  min-height: 100vh;
}
header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }
```

## 2. Responsive cards

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}
```

## 3. Sidebar that stacks on mobile

```css
.layout { display: grid; gap: 24px; }
@media (min-width: 800px) {
  .layout { grid-template-columns: 1fr 300px; }
}
```

## 4. Centre anything

```css
.center {
  display: grid;
  place-items: center;
  min-height: 60vh;
}
```

## 5. Full-bleed within a column

```css
.wrap { display: grid; grid-template-columns: 1fr min(65ch, 100%) 1fr; }
.wrap > * { grid-column: 2; }
.wrap > .full { grid-column: 1 / -1; }
```

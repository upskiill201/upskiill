Input and output are your first window into what a C program is doing.

## Direct answer

`printf` prints formatted text using specifiers such as `%d` for integers, `%f` for decimals, `%c` for characters and `%s` for strings. `scanf` reads input in the same format but needs the address of each variable, so use `&`. For lines of text, `fgets` is safer.

## Example

```c
#include <stdio.h>

int main(void) {
    int age;
    char name[30];

    printf("Name: ");
    scanf("%29s", name);

    printf("Age: ");
    scanf("%d", &age);

    printf("%s is %d years old\n", name, age);
    return 0;
}
```

## Specifiers

| Specifier | Type |
| :--- | :--- |
| `%d` | int |
| `%f` | float or double |
| `%c` | char |
| `%s` | string |
| `%zu` | size_t |

## Common mistakes

- Missing `&` in `scanf` for numbers.
- Wrong specifier for the type.
- Using `scanf("%s")` without a width limit.

This **AI roadmap for 2027** takes you from zero to useful, then from useful to building. There are two paths. The **AI user** path makes you better at your current job within weeks. The **AI engineer** path leads to a technical career and takes about a year. Both start in the same place, and you can follow either one on [Teyro](/courses/the-ai-stack) in short daily lessons.

## Direct answer

The AI roadmap for 2027 has six stages: **1. use AI tools well**, **2. understand how AI works**, **3. learn Python**, **4. learn data and SQL**, **5. learn machine learning basics**, **6. build AI apps with models, tools and agents**. Stages 1 and 2 are enough for most jobs. Stages 3 to 6 are the AI engineer path.

## The roadmap at a glance

| Stage | What you learn | Time | Path |
| :--- | :--- | :--- | :--- |
| 1. Use AI at work | Prompts, checking output, real tasks | 2 to 4 weeks | Everyone |
| 2. How AI works | Models, tokens, training data, limits | 2 to 4 weeks | Everyone |
| 3. Python | Code basics, files, libraries | 2 to 3 months | Engineer |
| 4. Data and SQL | Cleaning, querying, charts | 1 to 2 months | Engineer |
| 5. Machine learning | Training, testing, evaluation | 2 to 4 months | Engineer |
| 6. Build AI apps | APIs, retrieval, agents, evaluation | 2 to 4 months | Engineer |

## Stage 1: Use AI tools well

Start with tasks you already do: writing emails, summarising documents, planning projects, studying. Learn to give context, ask for a format and check the answer. Most people skip the checking step, and that is where AI goes wrong. [AI at Work: Beginner](/courses/ai-at-work-beginner) and [AI Tools for Everyday Productivity](/courses/ai-tools-for-everyday-productivity) cover this stage.

## Stage 2: Understand how AI works

You don't need maths here. Learn what a model is, why it sometimes makes things up, what training data does, and where AI is weak. This makes you better at using it and safer when you rely on it. [The AI Stack](/courses/the-ai-stack) explains the layers from chips to apps.

## Stage 3: Learn Python

Python is the main language for AI work. Learn variables, loops, functions, lists and dictionaries, then how to install and use libraries. See [best programming language to learn in 2027](/blog/best-programming-language-to-learn-in-2027) for why Python comes first.

## Stage 4: Learn data and SQL

AI runs on data. Learn to load a dataset, clean it, query it with SQL and make simple charts. These skills are also valuable on their own as a data analyst.

## Stage 5: Machine learning basics

Learn how a model learns from examples, how to split data into training and test sets, and how to measure accuracy, precision and recall. Build a few small models with scikit-learn. [Machine Learning for Beginners](/courses/machine-learning-for-beginners) teaches this with real code in the browser.

## Stage 6: Build AI apps

This is the AI engineer stage. Learn to call model APIs, give models your own data through retrieval, connect them to tools, and test whether the results are good enough. Coding agents are part of this now: [Working with AI Coding Agents](/courses/working-with-ai-coding-agents) teaches how to direct them well.

## AI engineer roadmap 2027: the portfolio

Employers want to see what you built. Aim for three projects:

1. **A data project.** Clean a public dataset and explain what you found.
2. **A machine learning model.** Predict something real and explain how well it works.
3. **An AI app.** A small tool that uses a model on your own data, with tests for its answers.

## Common mistakes

- **Jumping straight to deep learning.** Fundamentals come first.
- **Watching without building.** You only learn AI by using it on real problems.
- **Ignoring evaluation.** An AI feature that is right 80% of the time can still be useless. Learn to measure.
- **Studying in bursts.** A little every day beats a weekend binge once a month.

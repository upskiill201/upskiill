AI is no longer a future topic at work. Here is what it's actually used for today.

## Direct answer

At work, AI is mostly used to draft and edit writing, summarise documents and meetings, answer routine customer questions, analyse and visualise data, automate repetitive tasks and help write code. People still review and decide. The biggest gains come from using it on well-defined tasks, with checks.

## Examples by function

| Area | Common uses |
| :--- | :--- |
| Admin and office | Drafting emails, summarising meetings, scheduling |
| Customer service | Chat assistants, suggested replies, summaries of cases |
| Marketing | Draft copy, ideas, audience research, editing |
| Sales | Prepare for calls, write follow-ups |
| HR | Job descriptions, onboarding materials, answering policy questions |
| Finance and operations | Reports, spotting unusual numbers, forecasting support |
| Data and analytics | Cleaning, querying and explaining data |
| Software | Code suggestions, tests, documentation. See [AI coding agents](/blog/what-are-ai-coding-agents) |

## What works well

- Repetitive writing tasks
- First drafts that you then edit
- Summaries of long material
- Explaining unfamiliar topics

## Risks to manage

- **Wrong output:** AI can be confidently wrong.
- **Data leaks:** never paste confidential or personal data into unapproved tools. See [ChatGPT at work](/blog/chatgpt-at-work).
- **Bias:** check results that affect people.
- **Over-reliance:** keep your own skills sharp.

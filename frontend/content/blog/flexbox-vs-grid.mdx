They solve different problems, and good developers use both.

## Direct answer

Use Flexbox when you are arranging items along a single line, such as a navigation bar or a row of buttons. Use Grid when you need rows and columns together, such as a page layout or a gallery. They work well combined.

## Comparison

| | Flexbox | Grid |
| :--- | :--- | :--- |
| Dimension | one (row or column) | two (rows and columns) |
| Starts from | content | layout |
| Good for | nav bars, toolbars, centring | page layouts, galleries |

## Flexbox example

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
```

## Grid example

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}
```

## A quick test

If you think in "a row of things", try Flexbox. If you think in "a table of things", try Grid.

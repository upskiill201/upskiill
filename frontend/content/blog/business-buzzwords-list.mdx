Buzzwords come and go. Here is a list of common ones and what they usually mean.

## Direct answer

Business buzzwords are trendy, often vague phrases used in workplaces. Many have a plain English equivalent. Knowing them helps you follow meetings, but clear writing and speaking usually works better than using them.

## Meetings and planning

| Buzzword | Plain English |
| :--- | :--- |
| Align | Agree |
| Circle back | Return to this later |
| Take it offline | Discuss it separately |
| Parking lot | List of topics for later |
| Action item | A task |
| Deliverable | Something to hand over |
| Stakeholder | Anyone affected or interested |
| Buy-in | Support or agreement |

## Strategy and growth

| Buzzword | Plain English |
| :--- | :--- |
| Leverage | Use |
| Scalable | Works when bigger |
| Pivot | Change direction |
| Value-add | Extra benefit |
| Move the needle | Make a real difference |
| Low-hanging fruit | Easy wins |
| North star | Main goal |
| Game changer | Something very important |

## Work and time

| Buzzword | Plain English |
| :--- | :--- |
| Bandwidth | Capacity |
| Touch base | Quick check-in |
| Ping | Message |
| Loop in | Include |
| Heads-up | Warning |
| Ballpark | Rough estimate |
| EOD | End of day |
| ASAP | As soon as possible |

## People and culture

| Buzzword | Plain English |
| :--- | :--- |
| Onboarding | Getting a new person started |
| Upskill | Learn new skills |
| Empower | Give authority |
| Culture fit | Whether you suit the team |
| Right-size | Reduce staff (be wary) |
| Synergy | Teams working together well |

## Using them sensibly

- Use shared terms with your team if they save time.
- Avoid them with people outside the team.
- Write plain messages. See [plain language writing](/blog/plain-language-writing-guide).

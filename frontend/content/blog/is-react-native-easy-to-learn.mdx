React Native lets you build apps for Android and iPhone from one codebase. Whether it's easy depends on where you're starting.

## Direct answer

React Native is reasonably easy to start if you know basic JavaScript. You build screens from small reusable pieces and see results quickly. Complete beginners should learn JavaScript first, then React Native ideas such as components, state and navigation. Expect a small app in days to weeks and real confidence in a few months.

## What makes it easier

- One language (JavaScript) for both Android and iPhone
- Reusable components
- Fast refresh while you edit
- Large community and plenty of examples

## What's tricky

- Getting your tools set up
- Understanding state and how data flows
- Navigation between screens
- Differences between phones
- Publishing to app stores

## What to learn first

1. JavaScript basics. See [JavaScript for beginners](/blog/javascript-for-beginners-guide).
2. Components and props
3. State and events
4. Lists and navigation
5. Saving and loading data
6. Publishing

## How long?

| Goal | With regular practice |
| :--- | :--- |
| A first small app | Days to weeks |
| Comfortable building apps | A few months |
| Publishing to stores | Extra time for accounts and review |

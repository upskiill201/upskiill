AI can now produce a whole website from a short description. That's useful, but you're still the one responsible for it.

## Direct answer

To build a website with AI, write a clear brief (purpose, pages, tone, content), ask for one page or section at a time, review the result in a browser and on a phone, fix mistakes, then publish. AI speeds up the first draft. Knowing basic HTML and CSS lets you check and fix what it makes.

## A simple workflow

1. **Brief:** who is it for, what do they need, which pages.
2. **Generate one page.** Ask for plain HTML and CSS, so you can read it.
3. **Review it.** Does it say true things? Are contact details correct?
4. **Test on a phone.** See [what is responsive web design](/blog/what-is-responsive-web-design).
5. **Improve in small steps.** One change per request.
6. **Publish.** See [how to launch a website](/blog/how-to-launch-a-website).

## A good brief

> Create a one-page website for a bicycle repair shop in Leeds. Sections: what we fix, prices from a list I'll paste, opening hours, a contact form and a map link. Friendly tone. Use plain HTML and CSS, no frameworks, and make it work well on phones.

## What can go wrong

- Invented details, like fake reviews or wrong opening hours
- Layouts that break on small screens
- Missing alt text and poor contrast
- Unexpected code you don't understand
- Contact forms that don't actually send anything

## Why basic skills still matter

If you can read HTML and CSS you can spot a broken link, change a colour and fix spacing yourself. Learn the basics with [how to learn HTML and CSS](/blog/how-to-learn-html-and-css).

You don't need a degree to start learning data science. You need a plan and something to practise on.

## Direct answer

To learn data science from scratch: learn Python basics, learn pandas to clean and summarise data, study simple statistics, make charts, and practise on real datasets. Build small projects that answer a question and explain them clearly. Beginners usually see progress within weeks, but being job-ready takes months.

## A step-by-step plan

### Step 1: Get comfortable with data
Open a spreadsheet. What's in each column? What looks wrong?

### Step 2: Python basics
Variables, lists, loops, functions. See [is Python good for beginners](/blog/is-python-good-for-beginners) and the [Python course](/courses/python-for-beginners).

### Step 3: pandas
Load a table, filter, group and summarise.

```python
import pandas as pd

df = pd.read_csv("sales.csv")
print(df.groupby("region")["amount"].sum())
```

### Step 4: Clean messy data
Missing values, duplicates, odd entries.

### Step 5: Statistics basics
Averages, spread, outliers, comparing groups, and why correlation isn't cause.

### Step 6: Charts and story
A good chart plus two sentences beats a table of numbers.

### Step 7: Projects
Pick a question you care about, find a dataset, and write up what you found.

## How long does it take?

| Goal | Rough time with regular practice |
| :--- | :--- |
| First useful analysis | Weeks |
| Comfortable with Python and pandas | A few months |
| Job-ready portfolio | Many months |

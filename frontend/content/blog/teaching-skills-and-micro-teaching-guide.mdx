## Direct Answer: The 5 Core Micro-Teaching Skills at a Glance

```
┌─────────────────────────────────────────────────────────────┐
│                 THE 5 CORE MICRO-TEACHING SKILLS            │
├─────────────────────────────────────────────────────────────┤
│  1. SET INDUCTION (Intro) ──> Hook curiosity & prior knowledge
│  2. SKILL OF QUESTIONING ──> Socratic inquiry & probing cues │
│  3. SKILL OF EXPLANATION ──> Clear analogies & simple words  │
│  4. STIMULUS VARIATION   ──> Tone modulation, gestures, media│
│  5. REINFORCEMENT        ──> Positive feedback & praise     │
└─────────────────────────────────────────────────────────────┘
```

| Micro-Teaching Skill | Pedagogical Objective | Classroom Demonstration Technique |
| :--- | :--- | :--- |
| **1. Set Induction (Introduction)** | Hook attention and link to prior knowledge | Start with an intriguing real-world paradox or mystery |
| **2. Questioning & Probing** | Stimulate critical thinking beyond memorization | Ask open-ended questions and use "pause-and-bounce" techniques |
| **3. Skill of Explanation** | Break down complex mechanisms smoothly | Use the Feynman simplification model with physical analogies |
| **4. Stimulus Variation** | Combat classroom boredom and attention drift | Change vocal volume, move across the room, switch to visual media |
| **5. Reinforcement & Rewards** | Encourage student participation | Use positive verbal ("Brilliant insight!") and nonverbal nods |

## 1. The 6-Step Micro-Teaching Cycle

The micro-teaching feedback loop is the ultimate deliberate practice engine:

```
┌─────────────────────────────────────────────────────────────┐
│                 THE 36-MINUTE MICRO-TEACHING LOOP           │
├─────────────────────────────────────────────────────────────┤
│  [1. PLAN]       ──> Design a 6-minute mini-lesson plan     │
│  [2. TEACH]      ──> Deliver lesson to 5-10 peers (6 mins)  │
│  [3. FEEDBACK]   ──> Peer and supervisor critique (6 mins)  │
│  [4. RE-PLAN]    ──> Restructure based on feedback (12 mins)│
│  [5. RE-TEACH]   ──> Re-deliver to a new peer group (6 mins)│
│  [6. RE-FEEDBACK]──> Evaluate improvement metrics (6 mins)  │
└─────────────────────────────────────────────────────────────┘
```

## 2. The Skill of Questioning: The Socratic Method

Amateur teachers ask closed questions (*"Do you understand?"*). Pro educators use **probing questions**:

* **Prompting:** Helping a struggling student with a step-by-step hint.
* **Seeking Further Clarification:** *"What makes you choose that formula over another?"*
* **Refocusing:** Connecting a student's answer back to the main thesis.

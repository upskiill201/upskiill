Vibe coding lets beginners build real things quickly. The skill that makes it work is not typing code, it's directing and checking.

## Direct answer

To start vibe coding as a beginner, choose a tiny project, pick an AI coding tool, write a clear brief, build one feature at a time, test after every step and learn enough to read what the AI wrote. Finish small things first, then take on bigger ones.

## A beginner path

1. **Understand the idea.** Read [what is vibe coding](/blog/what-is-vibe-coding).
2. **Pick a project** you'll use yourself.
3. **Set up a tool.** See [Claude Code for beginners](/blog/claude-code-for-beginners) or [Cursor for beginners](/blog/cursor-ai-for-beginners).
4. **Write the brief.** Goal, features, look and limits.
5. **Build in small steps.** Run it every time.
6. **Test and fix.** Describe bugs exactly.
7. **Secure it.** No secrets in code.
8. **Publish.** Share it with a friend.

## Project ideas

| Project | Skills you'll practise |
| :--- | :--- |
| Habit tracker | Saving data, simple logic |
| Tip splitter | Forms and maths |
| Quiz | Lists and scoring |
| Budget page | Data and totals |
| Portfolio page | Layout and publishing |

## Good habits

- Save versions so you can undo
- Ask the AI to explain code you don't understand
- Test on a phone
- Keep a list of what broke and why

## Mistakes

- Asking for too much at once
- Accepting changes you didn't read
- Skipping tests
- Pasting secrets

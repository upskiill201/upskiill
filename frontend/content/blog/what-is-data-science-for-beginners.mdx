Data science sounds technical, but at its core it's answering questions with data.

## Direct answer

Data science is the practice of using data to answer questions: collecting and cleaning it, exploring it, finding real patterns and explaining what they mean so someone can decide. Beginners learn a few core steps: ask a good question, tidy messy data, summarise it, spot patterns and tell an honest story. Python is the most common tool.

## The data science workflow

1. **Ask a question** that someone cares about.
2. **Get the data.**
3. **Clean it:** fix missing values, duplicates and typos.
4. **Explore:** what's normal? what's unusual?
5. **Find patterns,** and check they are real.
6. **Tell the story** with a chart and plain words.

## Skills you'll need

| Skill | Why |
| :--- | :--- |
| Asking good questions | Data without a question is noise |
| Python and pandas | Clean and analyse data |
| Statistics basics | Know when a pattern is real |
| Charts | Show results clearly |
| Communication | Explain what it means |

SQL is a useful companion. See [how to learn SQL](/blog/how-to-learn-sql-for-beginners).

## Topics in a beginner syllabus

- Types of data and spreadsheets
- Cleaning data
- Averages, spread and outliers
- Comparing groups
- Correlation vs cause
- Charts and storytelling
- Simple prediction ideas

## Data science vs data analysis vs machine learning

- **Data analysis:** describing what happened.
- **Data science:** broader, includes modelling.
- **Machine learning:** algorithms that learn patterns to predict. Try [Machine Learning for Beginners](/courses/machine-learning-for-beginners) later.

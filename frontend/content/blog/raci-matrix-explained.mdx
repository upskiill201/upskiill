When everyone owns it, nobody owns it.

## Direct answer

A RACI matrix lists tasks and assigns each person a role: Responsible (does the work), Accountable (owns the result, only one per task), Consulted (gives input) and Informed (kept up to date). It removes confusion about who does what.

## Example

| Task | Ada | Ben | Chi | Dee |
| :--- | :--- | :--- | :--- | :--- |
| Write brief | R | A | C | I |
| Design | C | A | R | I |
| Launch | R | A | C | C |

## How to build one

1. List tasks or deliverables.
2. List people or teams.
3. Assign R, A, C and I.
4. Check: exactly one A per task.
5. Share and agree.

## Pitfalls

- Too many C and I roles slow things down.
- No clear A.
- Not updating it.

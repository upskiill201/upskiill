Installing Python is easy, but the first screens confuse many beginners. Here is the process step by step, and a way to learn without installing anything.

## Direct answer

Download Python from the official site, python.org. On Windows, tick **Add python.exe to PATH** in the installer, then install. On a Mac, run the installer. Open a terminal and type `python --version` (Windows) or `python3 --version` (Mac) to check. Then run a file with `python hello.py`.

## Install on Windows

1. Go to **python.org/downloads** and download the latest Python 3 installer.
2. Open the installer. On the first screen, **tick "Add python.exe to PATH"**. This is the step beginners miss.
3. Choose **Install Now** and wait for it to finish.
4. Open **Command Prompt** or **PowerShell** and type:

```
python --version
```

You should see a version number such as `Python 3.x.x`.

## Install on Mac

1. Download the macOS installer from **python.org/downloads** and open it.
2. Follow the steps.
3. Open **Terminal** and type:

```
python3 --version
```

On a Mac, the command is usually `python3`, not `python`.

## Run your first program

1. Create a file called `hello.py` in a folder you can find.
2. Put this inside:

```python
print("Hello, world!")
name = input("What is your name? ")
print("Nice to meet you,", name)
```

3. Open a terminal in that folder and run:

```
python hello.py
```

(Use `python3 hello.py` on a Mac.)

## Pick an editor

- **IDLE** comes with Python. Open it, choose File, New File, and run with F5. It is enough to start.
- **Visual Studio Code** is a popular free editor. Install the Python extension to run and debug.
- Any text editor works: Python files are just text.

## Common problems

- **"python is not recognized":** you missed the PATH box. Run the installer again, choose Modify or Uninstall, then reinstall with the box ticked.
- **Wrong version on a Mac:** use `python3`.
- **Cannot find the file:** your terminal must be in the same folder as `hello.py`. Use `cd folder-name` to move.
- **IndentationError:** check the spaces at the start of lines.

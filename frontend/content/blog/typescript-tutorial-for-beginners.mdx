TypeScript adds types to JavaScript so many mistakes are caught before your code runs. The basics are quick to learn if you know JavaScript.

## Direct answer

To learn TypeScript: learn JavaScript first, add type annotations to variables and functions, learn interfaces and union types, then generics and how it works with your tools. Practise in an online playground or compile files with the TypeScript compiler. The basics take days to a couple of weeks if you know JavaScript.

## Basic types

```ts
let name: string = "Sam";
let age: number = 30;
let isMember: boolean = true;
let scores: number[] = [10, 20, 30];
```

TypeScript will warn you if you try `age = "thirty"`.

## Functions

```ts
function greet(name: string, times: number = 1): string {
  return `Hello, ${name}! `.repeat(times);
}
```

## Interfaces

```ts
interface User {
  id: number;
  name: string;
  email?: string; // optional
}

const user: User = { id: 1, name: "Sam" };
```

## Union types

```ts
function printId(id: number | string) {
  console.log(id);
}
```

## Running TypeScript

Browsers can't run TypeScript directly. It's compiled to JavaScript:

1. Install Node.js.
2. Install TypeScript using the official instructions.
3. Write `app.ts`.
4. Compile with `tsc`.
5. Run the output.

Or use an online playground to start.

## Topics to learn

1. Basic types
2. Functions
3. Objects and interfaces
4. Unions and literal types
5. Generics
6. Working with libraries and frameworks

## How long?

If you already know JavaScript, a couple of weeks of regular practice covers the basics.

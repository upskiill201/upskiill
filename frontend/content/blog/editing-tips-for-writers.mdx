First drafts are for ideas. Edits are for readers.

## Direct answer

To edit well, draft first, leave it, then edit in passes: structure, clarity, brevity and finally typos. Read aloud, cut filler, replace long words with short ones and make sure each paragraph has one idea.

## 12 tips

1. Write first, edit later.
2. Let it rest.
3. Read aloud.
4. Cut the first paragraph if it only warms up.
5. Delete "very", "really", "just".
6. Prefer short words.
7. Use active voice.
8. One idea per paragraph.
9. Split long sentences.
10. Replace jargon with plain words.
11. Check facts and numbers.
12. Proofread last.

## A pass system

| Pass | Focus |
| :--- | :--- |
| 1 | structure and order |
| 2 | clarity |
| 3 | brevity |
| 4 | typos |

"Done" means different things to different people. Write it down.

## Direct answer

A definition of done is a checklist that says what must be true before work is finished, such as reviewed, tested, documented and approved. It removes arguments about quality and avoids hidden unfinished work.

## Examples

**Report:** proofread, figures checked, reviewed by a colleague, sent in the agreed format.

**Software feature:** code reviewed, tests passing, documentation updated, deployed to staging.

**Marketing campaign:** copy approved, links tested, tracking set up, scheduled.

## How to write one

1. Ask what mistakes have slipped through before.
2. List the checks that would have caught them.
3. Keep it short, ten items at most.
4. Agree as a team.
5. Review it regularly.

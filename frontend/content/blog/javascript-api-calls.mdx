APIs let your page use data from other services: weather, maps, quotes, your own backend.

## Direct answer

Call an API from JavaScript with `fetch`. Build the URL with query parameters, send JSON for POST requests, check `response.ok` and handle errors with `try/catch`. Never put private API keys in front-end code.

## GET with parameters

```javascript
const params = new URLSearchParams({ q: "london", units: "metric" });
const response = await fetch(`https://api.example.com/weather?${params}`);
const data = await response.json();
```

## POST with JSON

```javascript
const res = await fetch("/api/notes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title: "Hello" }),
});
```

## Handle problems

- **Network errors:** caught by `try/catch`.
- **HTTP errors:** check `response.ok`.
- **CORS errors:** the server must allow your origin.
- **Rate limits:** read the API's documentation.

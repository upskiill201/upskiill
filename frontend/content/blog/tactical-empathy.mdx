People agree more readily when they feel understood.

## Direct answer

Tactical empathy is understanding someone's perspective and showing it in your words. Techniques include labelling emotions, mirroring key words and asking calibrated questions such as "How can we make this work?". It builds trust and uncovers real concerns.

## Techniques

| Technique | Example |
| :--- | :--- |
| Label | "It seems like the deadline is a concern." |
| Mirror | repeat the last few words as a question |
| Calibrated question | "What would make this workable for you?" |
| Summarise | "So the main issue is cost and timing." |

## Use it honestly

The goal is understanding, not trickery.

## Direct answer

AI hallucinations in code are invented functions, parameters, packages or settings that look real. They happen because models generate likely-looking text rather than verifying facts. Protect yourself by running code, checking the official docs and verifying every new package before you install it.

## Typical forms

- A method that is not in the library.
- A configuration option that was removed or never existed.
- A package name that does not exist, which attackers can register to catch people out.
- Confident but wrong explanations.

## How to catch them

1. **Run it.** Errors reveal many hallucinations immediately.
2. **Check documentation** for any unfamiliar function.
3. **Verify packages** on the official registry: age, maintainers, downloads.
4. **Ask for sources** and then check them yourself.
5. **Give the AI the real docs** or the actual file to work from.

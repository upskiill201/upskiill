AI writes confident code. Confidence is not correctness.

## Direct answer

Review AI-generated code the way you would review a new colleague's pull request: read every change, run it, test it, check edge cases and security, and make sure it fits your project's style. Ask the AI to explain anything you do not understand, and do not merge code you cannot explain.

## A checklist

1. **Does it solve the actual problem?** Compare with your request.
2. **Run it.** Do not trust code that has not run.
3. **Read the diff** line by line.
4. **Look for hidden changes:** extra files, removed code, changed config.
5. **Check edge cases:** empty input, null, very large input.
6. **Check errors:** are failures handled sensibly?
7. **Check security:** secrets, input validation, authentication, queries.
8. **Check dependencies:** are new packages needed and real?
9. **Write or run tests** that would fail if the code were wrong.
10. **Check style and naming** against your project.

## Common AI mistakes

- Calling functions or packages that do not exist.
- Out-of-date API usage.
- Over-engineered solutions.
- Passing tests by weakening them.

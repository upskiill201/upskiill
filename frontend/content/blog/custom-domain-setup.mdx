Your site works on a temporary address. Now give it your own.

## Direct answer

To use your own domain, add it in your hosting dashboard, then create the DNS records it asks for at your domain registrar, usually an A record for the root domain and a CNAME for `www`. Wait for DNS to update, then enable HTTPS.

## Steps

1. **Add the domain** in your host's dashboard.
2. **Copy the DNS values** it shows.
3. **Log in to your registrar** and open DNS settings.
4. **Add the records** exactly as shown.
5. **Wait,** from a few minutes to a day.
6. **Enable HTTPS** and set one version as the main one.

## Typical records

| Type | Name | Value |
| :--- | :--- | :--- |
| A | `@` | host's IP address |
| CNAME | `www` | host's domain |

## Troubleshooting

- Remove old conflicting records.
- Check for typos.
- Use a DNS checker to see what the world sees.

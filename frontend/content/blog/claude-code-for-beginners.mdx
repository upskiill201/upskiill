Claude Code is one of the best-known AI coding agents. This guide explains what it is, how to get started and what to watch for, without assuming you are a developer.

## Direct answer

Claude Code is a coding agent from Anthropic. You open it in your project folder, describe what you want in plain language, and it reads your files, makes changes and runs commands while you review. It is not a free app: you need a paid plan that includes it or pay for API use, and the terms change, so check Anthropic's pricing page.

## What it does

- Reads your project to understand how it fits together
- Edits one or several files to complete a task
- Runs commands, such as your tests, and reads the results
- Explains code you do not understand
- Asks before taking certain actions, depending on your settings

It is an agent, not just autocomplete. If that difference is new, start with [what AI coding agents are](/blog/what-are-ai-coding-agents).

## How to install Claude Code

Install steps change, so use the official source:

1. Open Anthropic's **Claude Code documentation** and find the install page.
2. Pick your system: macOS, Linux, or Windows. On Windows the docs explain the options, including using WSL or PowerShell.
3. Run the install command shown there. It is usually one line.
4. Open a terminal in a project folder and type `claude`.
5. Sign in with your Anthropic account when asked.

If the install fails, the docs have a troubleshooting section. Do not paste install commands from random sites, since that is a common way to get malware.

## Is it free, and what does it cost?

There are two main ways to pay, and both change over time:

| Way to pay | How it works | Good for |
| :--- | :--- | :--- |
| A monthly plan | Fixed price with usage limits | Regular use at a predictable cost |
| API (pay as you go) | You pay for the amount you use | Occasional use, or a heavy user who wants control |

Check what your plan includes before you start, since limits can use up fast on large tasks. If you only want to try an agent for free, see [free AI coding assistants](/blog/best-free-ai-coding-assistants).

## Using it in VS Code and other editors

Claude Code can be used in the terminal inside an editor such as VS Code, and Anthropic offers extensions for some editors. If you prefer an editor built around AI, compare it in [Claude Code vs Cursor](/blog/claude-code-vs-cursor).

## Using it safely as a beginner

1. **Use version control.** Commit before you start, so you can undo anything.
2. **Start small.** Ask for one change, check it, then ask for the next.
3. **Read the changes.** If you cannot explain a change, do not keep it.
4. **Run the tests yourself.** An agent's "it works" is not proof.
5. **Keep secrets out.** Never paste passwords or API keys into a prompt or a file the agent can see.
6. **Be specific.** A clear brief with examples and limits beats a one-line request.

Strict mode is the difference between "TypeScript as a suggestion" and "TypeScript as a safety net".

## Direct answer

Setting `"strict": true` in `tsconfig.json` turns on several checks, including `noImplicitAny`, `strictNullChecks` and `strictFunctionTypes`. It catches more bugs at compile time, especially `null` and `undefined` mistakes. New projects should start with it on.

## What it catches

```typescript
// noImplicitAny
function double(x) {   // error: parameter has an implicit any type
  return x * 2;
}

// strictNullChecks
let name: string = null; // error
const user = users.find(u => u.id === 1);
console.log(user.name);  // error: user may be undefined
```

## Adopting it in an existing project

1. Turn on one flag at a time.
2. Fix the errors it reveals.
3. Use `// @ts-expect-error` sparingly for temporary exceptions.

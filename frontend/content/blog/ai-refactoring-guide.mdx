Refactoring means changing structure without changing behaviour. AI is fast at the first part and careless about the second.

## Direct answer

To refactor with AI safely, start with passing tests, commit, ask for one small change at a time, run the tests after each step and review the diff. If you do not have tests, write them first or refactor by hand in tiny steps.

## A safe workflow

1. **Run tests** and commit the current state.
2. **State the goal:** "Extract this logic into a function, no behaviour changes."
3. **Limit scope:** one file or one function.
4. **Review the diff.**
5. **Run tests and lint.**
6. **Commit** and repeat.

## Good refactoring tasks

- Renaming for clarity.
- Extracting repeated code.
- Splitting large functions.
- Removing dead code.

## When not to

- Without tests.
- Right before a release.
- When the goal is unclear.

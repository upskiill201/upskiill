## Direct answer

Bolt is an AI tool that generates and runs web apps directly in your browser from prompts. You can iterate by chatting, view and edit the code and deploy. It suits prototypes and learning. For anything real, review the code, handle secrets properly and test. Features and pricing change, so check the official site.

## A workflow

1. **Write a clear prompt** with the main features.
2. **Run the preview** and click through.
3. **Iterate in small steps.**
4. **Inspect the code** for anything surprising.
5. **Export or deploy** when you are happy.

## Good prompts

"Build a habit tracker with a list of habits, a daily check-off button and a weekly summary. Use a simple, clean design."

## Cautions

- Do not paste secrets into prompts.
- Test edge cases.
- Keep version history so you can go back.

Meet your data before you model it.

## Direct answer

Exploratory data analysis is looking at a dataset to understand its structure, quality and patterns. Check the shape and types, summarise numbers, find missing values and outliers, look at distributions and explore relationships between columns. It guides cleaning and modelling.

## Steps with pandas

```python
import pandas as pd

df = pd.read_csv("data.csv")

df.shape
df.head()
df.info()
df.describe()
df.isna().sum()
df["city"].value_counts()
df.corr(numeric_only=True)
```

## What to look for

1. **Shape:** how many rows and columns?
2. **Types:** are numbers stored as text?
3. **Missing values:** how many, and why?
4. **Distributions:** skewed, odd peaks?
5. **Outliers:** errors or real extremes?
6. **Relationships:** which columns move together?

## Plot it

```python
df["price"].hist()
df.plot.scatter(x="size", y="price")
```

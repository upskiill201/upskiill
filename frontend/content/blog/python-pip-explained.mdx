Python's strength is its packages, and pip is how you get them.

## Direct answer

pip is Python's package installer. Run `pip install name` to add a library, `pip uninstall name` to remove one and `pip list` to see what is installed. Use it inside a virtual environment to keep projects separate.

## Everyday commands

```bash
pip install requests
pip install requests==2.31.0
pip install --upgrade requests
pip uninstall requests
pip list
pip show requests
```

## Requirements files

```bash
pip freeze > requirements.txt
pip install -r requirements.txt
```

## Common problems

- **"pip is not recognised":** use `python -m pip install ...`.
- **Permission errors:** use a virtual environment instead of installing system-wide.
- **Wrong Python version:** check with `python --version` and `pip --version`.

WHERE decides which rows you get.

## Direct answer

`WHERE` filters rows using conditions. Combine conditions with `AND` and `OR`, test lists with `IN`, ranges with `BETWEEN` and text patterns with `LIKE`. Use `IS NULL` for missing values.

## Examples

```sql
SELECT * FROM orders WHERE total > 100;

SELECT * FROM customers
WHERE city = 'Lagos' AND active = 1;

SELECT * FROM products WHERE category IN ('books', 'games');

SELECT * FROM orders
WHERE created_at BETWEEN '2026-01-01' AND '2026-01-31';

SELECT * FROM customers WHERE name LIKE 'A%';

SELECT * FROM customers WHERE phone IS NULL;
```

## Operators

| Operator | Meaning |
| :--- | :--- |
| `=`, `<>` | equal, not equal |
| `>`, `<`, `>=`, `<=` | comparisons |
| `AND`, `OR`, `NOT` | combine conditions |
| `IN` | matches a list |
| `LIKE` | text pattern |

## Common mistakes

- Using `= NULL` instead of `IS NULL`.
- Mixing `AND` and `OR` without brackets.
- Forgetting quotes around text.

One small file controls how strict and how modern your TypeScript is.

## Direct answer

`tsconfig.json` is the TypeScript project configuration file. Create it with `npx tsc --init`. The options that matter most for beginners are `strict`, `target`, `module`, `outDir` and `include`.

## A starter config

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "strict": true,
    "outDir": "dist",
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}
```

## What the options do

| Option | Purpose |
| :--- | :--- |
| `target` | which JavaScript version to output |
| `module` | module system for imports |
| `strict` | turns on the strict checks |
| `outDir` | where compiled files go |
| `include` | which folders to compile |

## Tips

- Keep `strict` on for new projects.
- Framework templates usually give you a good tsconfig already.

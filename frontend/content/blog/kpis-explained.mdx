What gets measured gets managed, so measure carefully.

## Direct answer

A KPI is a measurable value that shows progress toward an important goal. Good KPIs are clear, tied to outcomes, owned by someone and reviewed regularly. Choose a few that matter and avoid vanity metrics.

## Examples

| Team | KPI examples |
| :--- | :--- |
| Sales | win rate, average deal size |
| Support | first response time, satisfaction score |
| Marketing | cost per lead, conversion rate |
| Finance | cash runway, days sales outstanding |

## Choosing good ones

1. Link each to a goal.
2. Make it measurable and available.
3. Assign an owner.
4. Set a target and a review rhythm.
5. Watch for unintended effects, such as gaming.

React Native lets you write one app and run it on Android and iPhone. Here is how to get started.

## Direct answer

To start with React Native: learn JavaScript basics, create a project with Expo (the easiest way to begin), build a screen from components such as `View`, `Text` and `Button`, add state to make it interactive, and run it on your phone. Build small things first.

## Setting up

1. Install Node.js from its official website.
2. Create a project using Expo's official instructions (they change, so use the current docs).
3. Start the development server.
4. Open the app on your phone with the Expo app, or use an emulator.

## A first screen with state

```jsx
import { useState } from 'react';
import { View, Text, Button } from 'react-native';

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>You tapped {count} times</Text>
      <Button title="Tap me" onPress={() => setCount(count + 1)} />
    </View>
  );
}
```

Each tap changes `count`, and the screen updates.

## Core ideas

| Idea | What it is |
| :--- | :--- |
| Components | Reusable building blocks like `View` and `Text` |
| Props | Data you pass into a component |
| State | Data that changes and updates the screen |
| Styles | A JavaScript way of describing layout |
| Navigation | Moving between screens |

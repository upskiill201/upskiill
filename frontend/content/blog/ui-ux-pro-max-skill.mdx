## 1. Advanced Figma Systems & Design Tokens

A "Pro Max" designer builds design files that mirror production code. This bridges the gap between design and frontend engineering:

* **Auto-Layout Mastery:** Using nested horizontal and vertical autolayout with min/max constraints and wrapping behavior for 100% responsive frames.
* **Figma Variables & Modes:** Creating light/dark mode variables, multi-brand palettes, and spatial spacing tokens (`4px`, `8px`, `16px`, `24px`, `32px`).
* **Interactive Component Sets:** Building reusable inputs, dropdowns, and buttons with interactive hover, active, disabled, and error states.

---

## 2. Behavioral UX Psychology: The Science of Habit Formation

Elite designers understand how human brains interact with visual stimuli:

1. **Hick's Law:** The time it takes to make a decision increases logarithmically with the number of choices. Eliminate unnecessary options on checkout and onboarding screens.
2. **Fitts's Law:** Critical interactive targets (like CTAs) must be large and positioned within easy thumb-reach on mobile interfaces.
3. **The Duolingo Effect:** Using gamified progress rings, daily streaks, and micro-rewards to create positive emotional loops (explore [how to stay consistent learning online](/blog/how-to-stay-consistent-learning-online)).

---

## 3. Micro-Interactions & Delightful Motion

Static screens feel dead. Modern apps incorporate smooth micro-interactions that communicate state changes:

* **Button Press State:** Slight scale down (`0.97`) with a 150ms spring easing.
* **Skeleton Loaders:** Gentle shimmering pulse while asynchronous data loads instead of jarring spinners.
* **Celebratory Animations:** Confetti or reward popups upon completing a milestone.

Closures sound scary, but the idea is simple: a function remembers where it came from.

## Direct answer

A closure is a function bundled with the variables around it when it was created. Even after the outer function returns, the inner function can still use those variables. Closures let you keep private state and build function factories.

## A counter

```javascript
function makeCounter() {
  let count = 0;
  return function () {
    count = count + 1;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

`count` is not accessible from outside, yet the returned function can use it.

## Function factory

```javascript
function multiplier(factor) {
  return n => n * factor;
}
const double = multiplier(2);
console.log(double(5)); // 10
```

## Common use cases

- Private variables
- Event handlers that need context
- Partial application and configuration

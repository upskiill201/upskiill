Most "performance problems" begin as unclear expectations. A few habits fix most of them.

## Direct answer

To set clear expectations, say what outcome you need, what good looks like, when it's due and how it ranks against other work. Agree who does what, check understanding by asking them to explain it back, and set a time to follow up. Put it in writing. Revisit when priorities change.

## The checklist

| Element | Example |
| :--- | :--- |
| Outcome | "A one-page summary of customer complaints" |
| Quality bar | "Accurate figures, no jargon, ready to send to the director" |
| Deadline | "Thursday noon" |
| Priority | "This comes before the newsletter" |
| Roles | "You write; Sam checks numbers" |
| Check-in | "Share a draft on Tuesday" |

## Check understanding

Ask: "To make sure I explained it well, how would you describe the task back to me?"

## New starters

Give 30-60-90 day goals, explain unwritten rules and set a weekly check-in.

## When expectations change

Say so clearly, explain why and update deadlines. Silent changes damage trust.

## When expectations are missed

1. Check whether the expectation was clear.
2. Describe the gap factually.
3. Ask what got in the way.
4. Agree a plan and date.
5. Follow up.

You don't need a PhD to start with machine learning. You need Python, data and curiosity.

## Direct answer

To learn machine learning from scratch: learn Python basics, learn to load and clean data, train a simple model, test it on data it hasn't seen, and repeat on different problems. Start with classic methods before deep learning. Free courses and public datasets are enough.

## The path

1. **Python basics.** See the [Python course](/courses/python-for-beginners).
2. **Data skills:** tables, cleaning, charts. See [learn data science from scratch](/blog/learn-data-science-from-scratch).
3. **Your first model.**
4. **Evaluate honestly.** Test on unseen data.
5. **Improve the data,** not just the model.
6. **Try different problems:** classification, prediction, grouping.
7. **Learn the theory gradually.**

## A tiny example

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=0)

model = KNeighborsClassifier()
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
```

It trains a model on flower measurements and checks it on flowers it hasn't seen.

## Common mistakes

- Testing on the same data you trained on
- Ignoring messy data
- Jumping to deep learning too soon

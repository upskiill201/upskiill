The difference is whether the answers are given.

## Direct answer

In supervised learning you train a model on labelled examples, such as emails marked spam or not spam, so it predicts labels for new data. In unsupervised learning there are no labels and the model finds structure on its own, such as grouping similar customers. Reinforcement learning learns from rewards.

## Comparison

| | Supervised | Unsupervised |
| :--- | :--- | :--- |
| Data | labelled | unlabelled |
| Goal | predict | discover structure |
| Examples | spam detection, price prediction | customer segments, anomaly detection |
| Algorithms | regression, decision trees | clustering, dimensionality reduction |

## Two kinds of supervised learning

- **Classification:** predict a category.
- **Regression:** predict a number.

## How to choose

1. Do you have labels? Try supervised.
2. Exploring unknown data? Try unsupervised.
3. Learning by trial and feedback? Consider reinforcement learning.

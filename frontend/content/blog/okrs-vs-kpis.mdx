## Direct answer

KPIs (key performance indicators) track how well something is performing day to day. OKRs (objectives and key results) set a goal to change something over a set period. Use KPIs to keep watch on essentials and OKRs to drive improvement.

## Comparison

| | KPIs | OKRs |
| :--- | :--- | :--- |
| Purpose | monitor health | drive change |
| Time | ongoing | quarterly or yearly |
| Example | monthly churn rate | cut churn from 5 percent to 3 percent |
| Review | regularly | regularly, scored at the end |

## Working together

If a KPI is off target, make improving it an OKR for the next quarter.

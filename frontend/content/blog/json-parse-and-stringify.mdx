Two functions that move data in and out of text.

## Direct answer

`JSON.parse(text)` turns a JSON string into a JavaScript object. `JSON.stringify(value)` turns a value into a JSON string. Wrap `JSON.parse` in `try/catch`, because invalid JSON throws an error.

## Examples

```javascript
const obj = JSON.parse('{"name":"Ada","age":28}');
const text = JSON.stringify({ name: "Ada", skills: ["math", "code"] }, null, 2);
```

The `null, 2` makes the output indented and easier to read.

## Safe parsing

```javascript
function safeParse(text, fallback = null) {
  try {
    return JSON.parse(text);
  } catch {
    return fallback;
  }
}
```

## What does not survive

| Value | Result |
| :--- | :--- |
| `undefined` and functions | dropped |
| `Date` | becomes a string |
| `NaN` and `Infinity` | become `null` |
| Circular references | throw an error |

It often adds words without adding information.

## Direct answer

Going forward means from now on. For example, "Going forward, send expenses by the 5th." It is often unnecessary. Use a clear date or "from now on" instead.

## Examples and fixes

| Original | Clearer |
| :--- | :--- |
| Going forward, we will review weekly. | We will review weekly. |
| Going forward, please copy me. | From now on, please copy me. |

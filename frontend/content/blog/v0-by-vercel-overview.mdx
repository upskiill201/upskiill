## Direct answer

v0 is Vercel's AI tool for generating user interfaces from prompts, usually producing React components styled with common libraries. It is useful for layouts, forms and dashboards. Use it as a starting point, refine with follow-up prompts and review accessibility and code quality before using it in a project.

## How to get good results

1. **Describe the purpose** and the user.
2. **Specify components:** "a pricing table with three plans".
3. **Mention constraints:** mobile first, accessible, dark mode.
4. **Iterate** with specific changes.
5. **Check accessibility:** labels, contrast, focus states.

## After generating

- Copy the code into your project.
- Replace placeholder data and images.
- Run lint and tests.

The compiler turns your text into a program.

## Direct answer

Compile a C file with `gcc main.c -o app` and run it with `./app`. Add `-Wall -Wextra` to see warnings, `-g` to include debugging information and list multiple files to compile them together.

## Common commands

```bash
gcc main.c -o app
gcc -Wall -Wextra -g main.c -o app
gcc main.c utils.c -o app
./app
```

## Useful flags

| Flag | Meaning |
| :--- | :--- |
| `-Wall -Wextra` | more warnings |
| `-g` | debugging info |
| `-O2` | optimise |
| `-std=c11` | choose the language standard |
| `-fsanitize=address` | catch memory errors |

## What happens during compile

1. **Preprocessing:** handles `#include` and `#define`.
2. **Compiling:** turns C into assembly.
3. **Assembling:** creates object files.
4. **Linking:** joins objects and libraries.

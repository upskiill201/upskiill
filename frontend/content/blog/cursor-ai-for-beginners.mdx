Cursor is a code editor built around AI. If you have heard of "vibe coding", you have probably seen it used. Here is what it is, how to set it up and how a beginner should use it.

## Direct answer

Cursor is an AI code editor based on the same foundation as VS Code. You write or open a project, then use chat, autocomplete or **agent mode** to ask the AI to make changes for you. Download it from Cursor's official site, sign in, and start with a small project. It has had a free plan with limits and paid plans, so check the current pricing yourself.

## What you can do in Cursor

- **Autocomplete:** it suggests the next lines as you type.
- **Chat:** ask questions about your code or how to do something.
- **Agent mode:** describe a task and it edits several files and can run commands. See [what AI coding agents are](/blog/what-are-ai-coding-agents).
- **Review changes:** you see what changed and accept or reject it.

## How to download and set it up

1. Go to Cursor's official website and download the installer for Windows, macOS or Linux. Avoid copies on other sites.
2. Run the installer and open Cursor.
3. Sign in or create an account.
4. If you use VS Code, import your settings and extensions when asked.
5. Open a folder (File, Open Folder) to use as your project.

## Free or paid

Cursor's plans change, so we do not list prices here. In general:

| Plan type | What to expect |
| :--- | :--- |
| Free | Limited use of the AI features, enough to try it |
| Paid | More use and access to more models, billed monthly |
| Student or team offers | Sometimes available, check the terms |

Heavy agent use can use up limits quickly. For other options, see [free AI coding assistants](/blog/best-free-ai-coding-assistants).

## A safe first project

1. Create a new empty folder and open it in Cursor.
2. Ask for something small and checkable, such as "a Python script that asks for my name and prints a greeting".
3. Read the code it wrote. Ask it to explain any line you do not follow.
4. Run it. Change one thing yourself.
5. Ask for one improvement at a time.

New to coding? Learn a little first with [is Python good for beginners](/blog/is-python-good-for-beginners), so you can tell when the AI is wrong.

## Habits that keep you out of trouble

- Use version control, so you can undo.
- Do not accept changes you cannot explain.
- Run the code and the tests yourself.
- Keep API keys and passwords out of files and prompts.
- Give clear briefs with an example and a limit.

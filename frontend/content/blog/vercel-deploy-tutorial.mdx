## Direct answer

To deploy on Vercel, sign in, import your Git repository, confirm the framework and build settings, add any environment variables and deploy. Each push creates a new deployment, and pull requests get preview URLs.

## Steps

1. **Push your project** to GitHub, GitLab or Bitbucket.
2. **Import it** on Vercel.
3. **Check settings:** framework, build command and output folder.
4. **Add environment variables,** such as API URLs. Never commit secrets to the repository.
5. **Deploy** and open the generated address.
6. **Add a domain** in Project settings.

## Useful habits

- Use preview deployments to review changes.
- Keep production on the main branch.
- Read build logs when something fails.

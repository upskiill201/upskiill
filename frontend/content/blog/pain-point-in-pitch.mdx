People buy relief from pain, not features.

## Direct answer

A pain point is a real, felt problem. Find it by interviewing customers, reading reviews and watching workflows. In a pitch, state the pain in the customer's words, show its cost and then show how you remove it.

## Types

| Type | Example |
| :--- | :--- |
| Financial | overpaying for tools |
| Productivity | wasting time on admin |
| Process | confusing steps |
| Support | slow replies |

## Using it

1. Open with the pain.
2. Quantify it if you can.
3. Show your solution.
4. Show the result.

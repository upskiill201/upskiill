## Why practise straight away?

Watching someone code feels like learning. Then you open an empty editor and nothing comes out. The gap between recognising an idea and using it only closes one way: by using it. Teyro puts that step inside every lesson, right after the idea is introduced, while it is still fresh.

## What does practice look like in a lesson?

After the **Learn** step, the **Apply** step asks you to do something with the idea:

- finish or fix a short piece of code
- pick the output a piece of code will produce
- choose the right approach for a small problem

Every answer is checked instantly. Right answers earn XP; wrong ones show you the correct answer so you are never left guessing.

## How do hearts work?

Hearts are there to make you slow down and think, not to stop you learning.

| | How it works |
| :--- | :--- |
| **Starting hearts** | 5 |
| **Wrong answer** | Costs 1 heart |
| **Refill over time** | 1 heart every 4 hours |
| **Refill now** | All five for 120 coins — coins you earn by learning, not by paying |
| **Protection** | A Perfect Lesson shield from the shop absorbs one mistake |

That last row is the difference from apps where the only way past an empty tank is a subscription.

## What happens after practice?

Next comes [reflection](/features/reflection-prompts) — putting the idea in your own words — and then an optional **Deepen** step. The full shape is on [short lessons](/features/short-lessons).

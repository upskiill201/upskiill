## How does Teyro choose my path?

During setup you answer a few questions: what you want to learn, why, and where you are starting from. Tey uses that to place you on a path. It takes under two minutes, and you can start your first lesson straight after.

## Why a path instead of a catalogue?

Choice is where many learners stall. Which language first? Which course? Which instructor? Every decision is a chance to put it off. A path removes the decision: open Teyro, and the next lesson is waiting.

## What does the path look like?

A single route of lessons, grouped into units, with your progress marked as you go — the same idea as a game map. Finished lessons stay open so you can revisit them.

## What subjects are there?

| Track | What it covers |
| :--- | :--- |
| **Coding** | Programming fundamentals, web development, mobile apps, software development |
| **AI** | Using AI tools well, building agents and automations |

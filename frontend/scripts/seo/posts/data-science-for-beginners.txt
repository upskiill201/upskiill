---

## Direct answer

NumPy provides the `ndarray`, a fast array that supports maths on whole arrays without loops. It underpins pandas, scikit-learn and many other data libraries. Learn how to create arrays, slice them and use functions like `mean` and `sum`.

## Basics

```python
import numpy as np

a = np.array([1, 2, 3, 4])
print(a * 2)          # [2 4 6 8]
print(a.mean())       # 2.5

m = np.array([[1, 2, 3], [4, 5, 6]])
print(m.shape)        # (2, 3)
print(m[0, 1])        # 2
print(m[:, 1])        # [2 5]
print(m.reshape(3, 2))
```

## Handy functions

| Function | Purpose |
| :--- | :--- |
| `np.arange(0, 10, 2)` | range of numbers |
| `np.zeros((2, 3))` | array of zeros |
| `np.random.rand(3)` | random numbers |
| `a.sum()`, `a.max()` | summaries |

## Boolean filtering

```python
a = np.array([5, 12, 7, 20])
print(a[a > 6])       # [12  7 20]
```

## The bottom line

Think in arrays, not loops.

=== mean-median-mode
title: Mean, Median and Mode: Differences, Examples and When to Use Each
desc: Mean, median and mode summarise data in different ways. Learn how to calculate each, when to use which and why outliers change the mean.
tags: mean median mode, mean vs median, how to calculate median, average types, statistics basics
rel: what-is-data-science-for-beginners
q: What is the difference between mean, median and mode? | Mean is the average, median is the middle value and mode is the most common value.
q: When is median better than mean? | When data has outliers or is skewed, such as incomes or house prices.
q: Can there be more than one mode? | Yes. A dataset can have several modes or none.
---
Three ways to say "typical", and they can disagree.

## Direct answer

The mean is the sum divided by the count. The median is the middle value when sorted. The mode is the most frequent value. Use the median when data has outliers, because the mean gets pulled toward extreme values.

## Example

Values: 2, 3, 3, 4, 100

- Mean = 112 ÷ 5 = 22.4
- Median = 3
- Mode = 3

The 100 pulls the mean up. The median stays near the typical value.

## In Python

```python
import statistics as st

data = [2, 3, 3, 4, 100]
print(st.mean(data), st.median(data), st.mode(data))
```

## Which to use

| Situation | Use |
| :--- | :--- |
| Symmetric data | mean |
| Skewed or outliers | median |
| Categories | mode |

## The bottom line

Always look at the data's shape before choosing an average.

=== correlation-vs-causation
title: Correlation vs Causation: Why Related Does Not Mean Caused
desc: Two things moving together does not prove one causes the other. Learn confounders, famous examples, how to test causes and why it matters for data science.
tags: correlation vs causation, correlation does not equal causation, spurious correlation, confounding variable, data science thinking
rel: what-is-data-science-for-beginners
q: What is the difference between correlation and causation? | Correlation means two variables move together. Causation means one produces a change in the other.
q: What is a confounding variable? | A hidden factor that influences both variables, creating a misleading link.
q: How can you test for causation? | Randomised experiments are the strongest method. Observational data needs careful design and caution.
---
Ice cream sales and sunburn rise together. Ice cream does not cause sunburn.

## Direct answer

Correlation shows that two variables move together. Causation means that changing one produces a change in the other. A third factor, a confounder, can cause both, as hot weather drives both ice cream sales and sunburn. Randomised experiments are the best way to show cause.

## Why correlations mislead

- **Confounders:** a hidden driver.
- **Coincidence:** random patterns in many variables.
- **Reverse causation:** the effect may cause the "cause".

## How to be careful

1. Ask what else could explain the link.
2. Check whether the cause came before the effect.
3. Look for experiments or natural experiments.
4. Be cautious with language: "is associated with", not "causes".

## In Python

```python
df[["hours", "score"]].corr()
```

## The bottom line

A correlation is a clue, not a conclusion.

=== handling-missing-data
title: How to Handle Missing Data: Drop, Fill or Flag?
desc: Missing values affect analysis. Learn the types of missingness, options like dropping, filling and flagging and pandas code for each, with cautions.
tags: missing data, handle missing values pandas, fillna dropna, data cleaning missing values, imputation
rel: exploratory-data-analysis, pandas-for-beginners
q: How do I find missing values in pandas? | Use df.isna().sum() to count missing values per column.
q: Should I delete rows with missing values? | Only if few rows are affected and the missingness is random. Otherwise you may bias results.
q: What is imputation? | Filling missing values with estimates such as the mean, median or a model prediction.
---
Empty cells are information too.

## Direct answer

To handle missing data, first understand why it is missing. Then choose: drop rows or columns if few are affected, fill values with a sensible estimate such as the median, or add a flag column showing that a value was missing. Document your choice because it can affect results.

## pandas examples

```python
import pandas as pd

df.isna().sum()                       # count missing per column
df.dropna(subset=["price"])           # drop rows missing price
df["age"] = df["age"].fillna(df["age"].median())
df["income_missing"] = df["income"].isna()
```

## Choosing a strategy

| Situation | Option |
| :--- | :--- |
| A few rows missing | drop |
| Numeric, skewed | fill with median |
| Category | fill with "unknown" |
| Missingness itself informative | add a flag |

## Cautions

- Fill using training data only if you are building a model.
- Do not fill blindly. Ask why the value is missing.

## The bottom line

Look, decide, document.

```python
import pandas as pd
```

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()
```

=== detect-outliers
title: Outliers: How to Detect Them and What to Do With Them
desc: Outliers are values far from the rest. Learn how to spot them with box plots and the IQR rule, and when to keep, fix or remove them.
tags: outliers, how to detect outliers, iqr rule, box plot outliers, data cleaning
rel: exploratory-data-analysis, mean-median-mode
q: What is an outlier? | A data point that is very different from most of the others.
q: How do I detect outliers? | Use box plots, the IQR rule or z-scores, and look at the data.
q: Should I always remove them? | No. They may be errors or important real events. Investigate first.
---
Some outliers are mistakes. Some are the story.

## Direct answer

An outlier is a value far from the rest of the data. Detect them with box plots, the interquartile range (IQR) rule or z-scores, then investigate. Remove or correct them if they are errors. Keep them if they are real and relevant.

## The IQR rule

A value is a potential outlier if it is below Q1 minus 1.5 times IQR or above Q3 plus 1.5 times IQR.

```python
q1 = df["price"].quantile(0.25)
q3 = df["price"].quantile(0.75)
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
outliers = df[(df["price"] < low) | (df["price"] > high)]
```

## What to do

| Cause | Action |
| :--- | :--- |
| Data entry error | fix or remove |
| Different group | analyse separately |
| Real extreme | keep, consider robust methods |

## The bottom line

Investigate before you delete.

## Direct answer

Use `element.addEventListener(type, handler)` to run a function when an event happens. Common types are `click`, `input`, `submit`, `keydown` and `mouseover`. The handler receives an event object with details such as the target element.

function onClick() { console.log("hi"); }

=== to-do-list-app-javascript
title: Build a To-Do List App in JavaScript: Step by Step
desc: Build a to-do list app with HTML, CSS and JavaScript: add, complete and delete tasks, and save them in localStorage. Full code included.
tags: to do list app javascript, javascript to do list, javascript project for beginners, build todo app, vanilla javascript project
rel: javascript-localstorage
q: Is a to-do list a good first JavaScript project? | Yes. It covers the DOM, events, arrays and storage in one small app.
q: How do I save tasks? | Store the tasks array in localStorage using JSON.stringify and load it with JSON.parse.
q: What can I add next? | Editing, filters, due dates, drag and drop and a clear completed button.
---
A to-do list is the classic first project for a reason.

## Direct answer

A to-do list app needs an input, a button, a list and a few functions: add a task, toggle done, delete and save. Keep tasks in an array, render the array to the page and save it to `localStorage` after every change.

## HTML

```html
<form id="form">
  <input id="text" placeholder="Add a task" required>
  <button>Add</button>
</form>
<ul id="list"></ul>
```

## JavaScript

```javascript
const form = document.querySelector("#form");
const text = document.querySelector("#text");
const list = document.querySelector("#list");

let tasks = JSON.parse(localStorage.getItem("tasks")) || [];

function save() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

function render() {
  list.innerHTML = "";
  tasks.forEach((task, index) => {
    const li = document.createElement("li");
    li.textContent = task.text;
    if (task.done) li.style.textDecoration = "line-through";
    li.addEventListener("click", () => {
      task.done = !task.done;
      save();
      render();
    });
    const del = document.createElement("button");
    del.textContent = "Delete";
    del.addEventListener("click", (e) => {
      e.stopPropagation();
      tasks.splice(index, 1);
      save();
      render();
    });
    li.append(del);
    list.append(li);
  });
}

form.addEventListener("submit", (e) => {
  e.preventDefault();
  tasks.push({ text: text.value, done: false });
  text.value = "";
  save();
  render();
});

render();
```

## Ideas to extend it

- Edit a task.
- Filter all, active and done.
- Add due dates.

## The bottom line

Small app, big lessons. Build it, then change it.

=== debounce-javascript
title: Debounce in JavaScript: What It Is and How to Write One
desc: Debounce delays a function until the user stops triggering it. Learn why it matters for search boxes and resize events, with a simple implementation.
tags: debounce, javascript debounce, debounce function, debounce vs throttle, search input debounce
rel: javascript-event-listeners
q: What is debounce? | A technique that delays running a function until a set time has passed since it was last called.
q: What is the difference between debounce and throttle? | Debounce waits until activity stops. Throttle runs at most once per interval while activity continues.
q: When should I use debounce? | Search-as-you-type, window resize handlers and auto-save.
---
Without debounce, typing "hello" can fire five network requests.

## Direct answer

Debounce wraps a function so it only runs after the user has stopped triggering it for a set delay. It reduces unnecessary work, such as sending a search request on every keystroke.

## Implementation

```javascript
function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

const search = debounce((query) => {
  console.log("Searching for", query);
}, 300);

input.addEventListener("input", (e) => search(e.target.value));
```

## Debounce vs throttle

| | Debounce | Throttle |
| :--- | :--- | :--- |
| Runs | after activity stops | at regular intervals |
| Good for | search, auto-save | scroll, resize |

## The bottom line

Debounce is a closure plus `setTimeout`. A small function with a big impact.

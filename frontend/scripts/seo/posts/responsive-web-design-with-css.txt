=== css-media-queries-explained
title: CSS Media Queries Explained: Syntax, Breakpoints and Examples
desc: Learn how CSS media queries work: min-width and max-width, common breakpoints, orientation, prefers-color-scheme and a mobile-first example.
tags: media queries, css media queries, media query examples, min-width max-width, responsive css
rel: what-is-responsive-web-design
q: What is a media query? | A CSS rule that applies styles only when conditions such as screen width or user preferences are met.
q: What is the difference between min-width and max-width? | min-width applies styles at that width and above. max-width applies styles at that width and below.
q: Should I use mobile-first? | Usually yes. Write base styles for small screens and add min-width queries for larger ones.
---
Media queries are how one stylesheet adapts to many screens.

## Direct answer

A media query applies CSS only when a condition is true, such as a minimum screen width. Write base styles for small screens, then add `@media (min-width: ...)` blocks for larger ones. You can also query orientation, colour scheme and reduced motion.

## Mobile-first example

```css
.layout {
  display: grid;
  gap: 16px;
}

@media (min-width: 768px) {
  .layout {
    grid-template-columns: 1fr 1fr;
  }
}

@media (min-width: 1100px) {
  .layout {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

## Other useful queries

```css
@media (prefers-color-scheme: dark) { body { background: #111; color: #eee; } }
@media (prefers-reduced-motion: reduce) { * { animation: none; } }
@media (orientation: landscape) { .hero { min-height: 60vh; } }
@media print { nav { display: none; } }
```

## Tips

- Choose breakpoints where your design breaks, not for specific devices.
- Keep queries near the components they change.

## The bottom line

Start small, add queries as the layout needs space. See [breakpoints](/blog/css-breakpoints-guide).

=== viewport-meta-tag
title: The Viewport Meta Tag: Why Your Site Looks Tiny on Mobile
desc: Learn what the viewport meta tag does, the correct tag to use, what the options mean and how to fix a mobile page that looks zoomed out.
tags: viewport meta tag, viewport meta tag explained, meta viewport mobile, width=device-width, fix mobile zoom
rel: what-is-responsive-web-design
q: What does the viewport meta tag do? | It tells mobile browsers to match the page width to the device width instead of pretending to be a wide desktop screen.
q: What is the correct viewport tag? | meta name="viewport" content="width=device-width, initial-scale=1".
q: Should I disable zooming? | No. Disabling zoom harms accessibility.
---
Without this tag, a phone treats your site as a tiny desktop page.

## Direct answer

Add `<meta name="viewport" content="width=device-width, initial-scale=1">` inside the `<head>`. It tells mobile browsers to use the device width and not zoom out to fit a desktop layout. Without it, media queries behave unexpectedly.

## Example

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My site</title>
</head>
```

## What the parts mean

| Part | Meaning |
| :--- | :--- |
| `width=device-width` | use the screen's real width |
| `initial-scale=1` | start with no zoom |

## Avoid

- `user-scalable=no` or `maximum-scale=1`, which block pinch-zoom and hurt accessibility.

## The bottom line

One line in the head makes responsive CSS work on phones.

=== css-breakpoints-guide
title: CSS Breakpoints: How to Choose Them for Responsive Design
desc: Breakpoints are the widths where your layout changes. Learn common values, why content-based breakpoints beat device-based ones and how to test them.
tags: css breakpoints, responsive breakpoints, common breakpoints, bootstrap breakpoints, mobile first breakpoints
rel: css-media-queries-explained
q: What are common CSS breakpoints? | Many projects use around 480, 768, 1024 and 1280 pixels, but there is no single standard.
q: Should I base breakpoints on devices? | Better to base them on where your content breaks, since device sizes change constantly.
q: How many breakpoints do I need? | Often two or three are enough if the layout is flexible.
---
There is no magic list of breakpoints. Your content decides.

## Direct answer

A breakpoint is a screen width at which your layout changes. Common starting points are about 480, 768, 1024 and 1280 pixels, but the best breakpoints are where your design starts to look bad. Resize the browser, find where it breaks and add a breakpoint there.

## A simple set

```css
/* base: phones */
@media (min-width: 640px)  { /* large phones, small tablets */ }
@media (min-width: 900px)  { /* tablets and small laptops */ }
@media (min-width: 1200px) { /* desktops */ }
```

## How to find yours

1. Open DevTools and switch to responsive mode.
2. Drag the width slowly.
3. Note where text lines get too long, columns squeeze or things overlap.
4. Add a query there.

## Tips

- Use fewer breakpoints with flexible units (`%`, `fr`, `clamp()`).
- Test real devices when you can.
- Name breakpoints with CSS variables or a comment legend.

## The bottom line

Let the content set the breakpoints.

=== fluid-typography-css
title: Fluid Typography in CSS: Text That Scales With the Screen
desc: Learn fluid typography with clamp() and viewport units to make headings scale smoothly between a minimum and maximum size, without media queries.
tags: fluid typography, css fluid font size, clamp typography, responsive font size, vw font size
rel: clamp-css-function
q: What is fluid typography? | Text that scales smoothly with the viewport width instead of jumping between sizes at breakpoints.
q: How do I make fluid font sizes? | Use clamp with a minimum size, a preferred value using vw and a maximum size.
q: Is vw alone enough? | No. Pure vw can get too small or too large and ignores user font settings. Combine it with rem in clamp.
---
Big headings on desktop shrink gracefully on phones.

## Direct answer

Use the CSS `clamp(min, preferred, max)` function to set a font size that scales with the screen but never goes below a minimum or above a maximum. Combine `rem` and `vw` so users' font preferences still count.

## Example

```css
h1 {
  font-size: clamp(2rem, 1.2rem + 4vw, 4rem);
}

p {
  font-size: clamp(1rem, 0.95rem + 0.3vw, 1.125rem);
}
```

## How it works

1. Below the minimum width, the size stays at `2rem`.
2. In between, it grows with the viewport.
3. Past the maximum, it stops at `4rem`.

## Tips

- Add a `rem` part to the preferred value so zoom and user settings still work.
- Test at several widths.
- Keep line length around 60 to 75 characters with `max-width: 65ch`.

## The bottom line

Fluid type removes many font-size media queries.

A card in a narrow sidebar and the same card in a wide main column should both look right.

## Direct answer

Container queries apply styles based on the size of a container element. Mark a parent with `container-type: inline-size`, then use `@container (min-width: ...)` to change its children. They make components reusable wherever they are placed.

```html
<div class="card-wrap">
```

- Reusable components placed in different contexts.
- Design systems.

- User preferences like dark mode.

=== clamp-css-function

q: What is the syntax? | clamp(minimum, preferred, maximum).

---
One function that replaces many media queries.

## Direct answer

`clamp(min, preferred, max)` returns the preferred value, but never smaller than `min` or larger than `max`. Use it for fluid font sizes, padding and widths that adapt smoothly to the screen.

## Examples

```css
.container {

}
```

```css
width: min(100%, 600px);  /* the smaller of two */
width: max(50%, 300px);   /* the larger of two */
```

## Tips

- Combine units like `rem` and `vw`.
- Test the extremes: narrow phones and wide monitors.

## The bottom line

clamp() makes fluid design simple and readable.

=== srcset-and-sizes
title: srcset and sizes Explained: How Browsers Pick an Image
desc: Understand the srcset and sizes attributes: width descriptors, density descriptors, how the browser chooses an image and common mistakes.
tags: srcset, sizes attribute, srcset explained, responsive image srcset, image width descriptors
rel: responsive-images-guide
q: What does srcset do? | It gives the browser a list of image files and their widths so it can choose the best one.
q: What does the sizes attribute do? | It tells the browser how wide the image will be displayed, so it can choose from srcset before layout is known.
q: Do I always need sizes? | Use it with width descriptors. Without it, the browser assumes the image fills the viewport.
---
You offer options. The browser picks.

## Direct answer

`srcset` lists image candidates with their pixel widths, such as `photo-800.jpg 800w`. `sizes` describes how wide the image will appear in your layout. The browser uses both, plus screen density, to download the best image.

## Example

```html
<img
  src="cat-800.jpg"
  srcset="cat-400.jpg 400w, cat-800.jpg 800w, cat-1200.jpg 1200w"
  sizes="(min-width: 1000px) 400px, 100vw"
  alt="A cat on a windowsill"
  width="800" height="600">
```

## Reading it

- Screens 1000 pixels and wider show the image about 400 pixels wide.
- Smaller screens show it at full width.

## Density descriptors

```html
<img src="logo.png" srcset="logo.png 1x, logo@2x.png 2x" alt="Logo">
```

## Mistakes

- Using `w` descriptors without `sizes`.
- Making files that are not actually the stated width.
- Forgetting `alt`.

## The bottom line

Provide choices and describe the layout. The browser handles the rest.

=== css-min-max-functions
title: CSS min(), max() and clamp(): When to Use Each
desc: Compare the CSS comparison functions min, max and clamp with examples for widths, padding and font sizes, and tips on mixing units.

q: What does max do? | It picks the largest of its values, useful for setting a minimum size.
q: When do I use clamp instead? | When you want both a minimum and a maximum with a flexible value in between.

Three small functions that give CSS some logic.

## Direct answer

`min()` returns the smallest value, `max()` the largest and `clamp()` keeps a value between a minimum and maximum. Use them to create flexible widths and spacing without media queries.

## Examples

```css
.box {

.sidebar {

.title {
  font-size: clamp(1.5rem, 4vw, 3rem);
```

| Function | Think of it as |
| :--- | :--- |

```html
<nav aria-label="Main">
```

```javascript
const btn = document.querySelector(".menu-btn");
```

=== rem-vs-em
title: rem vs em in CSS: The Difference and When to Use Each
desc: rem is relative to the root font size and em to the parent. Learn how they compound, examples and a simple rule for choosing between them.
tags: rem vs em, css rem, css em, rem and em units, relative units css
rel: css-units-rem-em-px
q: What is the difference between rem and em? | rem is relative to the root element's font size. em is relative to the current element's font size, which can compound when nested.
q: Which should I use for font sizes? | rem is predictable. Use em when you want spacing to scale with a component's text size.
q: Why do em units get confusing? | Because nested elements multiply, so a 1.2em inside another 1.2em becomes larger than expected.
---
Both scale with text size, but from different starting points.

## Direct answer

`rem` is based on the root (`html`) font size, so it is consistent everywhere. `em` is based on the element's own font size, so nested elements can compound. Use `rem` for most sizing and `em` for things that should scale with their own text, such as button padding.

## Example

```css
html { font-size: 100%; }     /* 16px by default */

h1 { font-size: 2rem; }       /* 32px */

.button {
  font-size: 1rem;
  padding: 0.5em 1em;         /* scales with the button's text */
}
```

## The compounding trap

```css
ul { font-size: 1.2em; }
ul ul { font-size: 1.2em; }   /* now 1.44 times the base */
```

## Rule of thumb

| Use | For |
| :--- | :--- |
| `rem` | font sizes, spacing, layout |
| `em` | component padding that follows its text |

## The bottom line

Default to `rem`, reach for `em` on purpose.

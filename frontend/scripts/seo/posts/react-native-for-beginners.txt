=== what-is-expo-react-native
title: What Is Expo? The Easiest Way to Start With React Native
desc: Expo is a framework and set of tools for building React Native apps. Learn what it does, how to start a project, Expo Go and when to go beyond it.
tags: expo, what is expo, expo react native, expo go, expo vs react native cli

q: What is Expo? | A framework and platform built around React Native that simplifies setup, development, building and updating apps.
q: Do I need Expo to use React Native? | No, but it is the recommended way for most new projects because it removes a lot of setup.
q: What is Expo Go? | An app you install on your phone to preview your project quickly while developing.
---
Setting up native tooling used to be the hardest part of React Native. Expo takes that away.

## Direct answer

Expo is a framework and set of services for building React Native apps. It handles project setup, a development server, common device features and building for the app stores. You can start with one command and preview your app on a real phone with Expo Go.

## Start a project

```bash
npx create-expo-app my-app
cd my-app
npx expo start
```

Scan the QR code with Expo Go on your phone, or press a key to open a simulator.

## What Expo gives you

- File-based routing with Expo Router.
- Libraries for camera, location, notifications and more.
- Tools to build and submit apps.
- Over-the-air updates for JavaScript changes.

## When to go beyond Expo Go

If you need custom native code, create a development build. Expo supports this without abandoning the workflow.

## The bottom line

Start with Expo. You can always customise later.

=== react-native-flatlist
title: React Native FlatList: Render Long Lists the Right Way

rel: react-native-core-components
q: What is FlatList? | A React Native component that renders long lists efficiently by drawing only the items on screen.
q: What is the difference between FlatList and ScrollView? | ScrollView renders all children at once. FlatList renders items lazily, so it is better for long lists.
q: Why do I get a key warning? | Items need a stable unique key. Provide a keyExtractor.
---
Lists are in nearly every app, and FlatList keeps them smooth.

## Direct answer

`FlatList` renders long lists efficiently by only drawing items near the screen. Give it a `data` array, a `renderItem` function and a `keyExtractor`. Use it instead of mapping over a `ScrollView` for anything beyond a few items.

## Example

```jsx
import { FlatList, Text, View } from "react-native";

const DATA = [
  { id: "1", title: "Learn React Native" },
  { id: "2", title: "Build a screen" },
  { id: "3", title: "Ship the app" },
];

export default function List() {
  return (
    <FlatList
      data={DATA}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <View style={{ padding: 16 }}>
          <Text>{item.title}</Text>
        </View>
      )}
      ItemSeparatorComponent={() => <View style={{ height: 1, backgroundColor: "#eee" }} />}
    />
  );
}
```

## Useful props

| Prop | Purpose |
| :--- | :--- |
| `onRefresh`, `refreshing` | pull to refresh |
| `onEndReached` | load more |
| `ListEmptyComponent` | empty state |
| `ListHeaderComponent` | header |

## Performance tips

- Keep `renderItem` light and consider `React.memo`.
- Use stable keys.
- Avoid inline heavy functions where possible.

## The bottom line

Use FlatList for long lists and provide good keys.

=== usestate-in-react-native
title: useState in React Native: Add State to Your Components
desc: Learn how useState works in React Native with a counter and a text input, why you must not mutate state, and updating objects and arrays.
tags: usestate, react native usestate, react state, state management basics, hooks for beginners
rel: props-and-state-react-native
q: What does useState do? | It adds a state variable to a component and gives you a function to update it, re-rendering when it changes.
q: Why does my UI not update? | You may be mutating state directly instead of using the setter, or using the old value in a closure.
q: How do I update an object or array in state? | Create a new copy, for example with the spread operator, instead of changing the existing one.
---
State is how a screen remembers things.

## Direct answer

`useState` returns a value and a setter. Calling the setter updates the value and re-renders the component. Never change state directly. Create new objects and arrays instead.

## Example

```jsx
import { useState } from "react";
import { View, Text, Button, TextInput } from "react-native";

export default function Counter() {
  const [count, setCount] = useState(0);
  const [name, setName] = useState("");

  return (
    <View style={{ padding: 16 }}>
      <TextInput value={name} onChangeText={setName} placeholder="Your name" />
      <Text>Hello {name}, count is {count}</Text>
      <Button title="Add" onPress={() => setCount(count + 1)} />
    </View>
  );
}
```

## Updating objects and arrays

```jsx
const [todos, setTodos] = useState([]);

setTodos([...todos, { id: Date.now(), text: "New" }]);       // add
setTodos(todos.filter((t) => t.id !== id));                  // remove
setUser({ ...user, name: "Ada" });                           // update field
```

## Use the functional form when it depends on the previous value

```jsx
setCount((c) => c + 1);
```

## The bottom line

State changes cause re-renders. Treat it as read-only.

=== useeffect-in-react-native
title: useEffect in React Native: Side Effects, Dependencies and Cleanup
desc: Learn useEffect for fetching data, timers and subscriptions in React Native. Understand the dependency array, cleanup and common infinite loop bugs.
tags: useeffect, react native useeffect, useeffect dependency array, useeffect cleanup, react hooks
rel: usestate-in-react-native
q: What is useEffect used for? | Running code that interacts with the outside world, such as fetching data, timers and subscriptions, after rendering.
q: What does the dependency array do? | It tells React when to re-run the effect. An empty array runs once after the first render.
q: Why does my effect run forever? | The effect updates state that is also in its dependencies, or an object or function dependency changes each render.
---
Components render. Effects do things after rendering.

## Direct answer

`useEffect(fn, deps)` runs `fn` after rendering. The dependency array controls when it re-runs: `[]` once, `[value]` when `value` changes and no array on every render. Return a function to clean up timers or subscriptions.

## Fetching data

```jsx
import { useEffect, useState } from "react";

function Users() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    let cancelled = false;
    async function load() {
      const res = await fetch("https://jsonplaceholder.typicode.com/users");
      const data = await res.json();
      if (!cancelled) setUsers(data);
    }
    load();
    return () => { cancelled = true; };
  }, []);

  return null;
}
```

## Timers with cleanup

```jsx
useEffect(() => {
  const id = setInterval(() => console.log("tick"), 1000);
  return () => clearInterval(id);
}, []);
```

## Common mistakes

- Missing dependencies.
- Updating state inside an effect that depends on it.
- Forgetting cleanup.

## The bottom line

Effects are for syncing with the outside world. Keep dependencies honest.

=== react-native-api-calls
title: Fetching Data in React Native: fetch, Loading States and Errors
desc: Learn how to call an API from React Native with fetch, show loading and error states, handle empty results and avoid common network problems on devices.
tags: react native api calls, react native fetch, fetch data react native, loading state, error handling
rel: useeffect-in-react-native
q: How do I call an API in React Native? | Use the built-in fetch function, usually inside useEffect, and store the result in state.
q: Why does my API work in the browser but not on my phone? | You may be using localhost, which refers to the phone itself. Use your computer's local network address or a deployed URL.
q: How do I show loading and error states? | Keep separate state for loading and error, and render different UI for each.
---
Real apps get data from servers. Real apps also handle slow and failing networks.

## Direct answer

Use `fetch` in a `useEffect`, store the result in state and keep separate states for loading and errors. On a device, never use `localhost` for your own server. Use your computer's network address or a deployed URL.

## Example

```jsx
import { useEffect, useState } from "react";
import { ActivityIndicator, FlatList, Text, View } from "react-native";

export default function Posts() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    (async () => {
      try {
        const res = await fetch("https://jsonplaceholder.typicode.com/posts");
        if (!res.ok) throw new Error("HTTP " + res.status);
        setPosts(await res.json());
      } catch (e) {
        setError(e.message);
      } finally {
        setLoading(false);
      }
    })();
  }, []);

  if (loading) return <ActivityIndicator />;
  if (error) return <Text>Something went wrong: {error}</Text>;
  if (posts.length === 0) return <Text>No posts yet</Text>;

  return (
    <FlatList
      data={posts}
      keyExtractor={(p) => String(p.id)}
      renderItem={({ item }) => <Text style={{ padding: 12 }}>{item.title}</Text>}
    />
  );
}
```

## The bottom line

Loading, error, empty and success: handle all four states.

=== props-and-state-react-native
title: Props vs State in React Native: What's the Difference?

tags: props and state, react native props, props vs state, lifting state up, react data flow

q: What is the difference between props and state? | Props are inputs passed from a parent. State is data a component owns and can change.

---
Two ideas run all of React: data in, data owned.

## Direct answer

Props are values passed into a component by its parent and are read-only. State is data that a component owns and can update, causing a re-render. When siblings need the same data, move the state up to their parent and pass it down as props.

## Example

```jsx
function Greeting({ name }) {          // prop
  return <Text>Hello {name}</Text>;
}

export default function App() {
  const [name, setName] = useState("Ada"); // state

  return (
    <View>
      <Greeting name={name} />
      <TextInput value={name} onChangeText={setName} />
    </View>
  );
}
```

## Comparison

| | Props | State |
| :--- | :--- | :--- |
| Owned by | parent | the component |
| Can change | no | yes, with the setter |
| Purpose | configure | remember |

## Lifting state up

Keep state in the closest common parent and pass the value and the setter to children.

## The bottom line

Props flow down, events flow up.

=== react-native-animations
title: React Native Animations: Animated API and Reanimated Basics
desc: An introduction to animation in React Native: the built-in Animated API, Reanimated for smoother gesture-driven motion and tips for performance.
tags: react native animations, animated api react native, reanimated, react native fade in, animation performance
rel: react-native-styling-guide
q: How do I animate in React Native? | Use the built-in Animated API for simple animations, or Reanimated for complex, gesture-driven ones.
q: Should I use the native driver? | Yes, where supported. It runs animations on the native side for smoother results.
q: Which properties animate smoothly? | Opacity and transform, such as translate and scale.
---
Motion makes an app feel polished, as long as it stays smooth.

## Direct answer

For simple animations, use React Native's built-in `Animated` API with `useNativeDriver: true`. For complex or gesture-based motion, use the Reanimated library. Animate `opacity` and `transform` for best performance, and respect reduced-motion settings.

## Fade-in example

```jsx
import { useEffect, useRef } from "react";
import { Animated, Text } from "react-native";

export default function FadeIn() {
  const opacity = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    Animated.timing(opacity, {
      toValue: 1,
      duration: 400,
      useNativeDriver: true,
    }).start();
  }, [opacity]);

  return <Animated.Text style={{ opacity }}>Welcome</Animated.Text>;
}
```

## Tips

- Keep animations short and purposeful.
- Animate transform and opacity.
- Test on a real device.
- Check the accessibility setting for reduced motion.

## The bottom line

Start with Animated, move to Reanimated when you need more.

You do not need a phone on your desk to start, but you do need one before launch.

## Direct answer

For iOS, use the iOS Simulator that comes with Xcode on a Mac. For Android, install Android Studio and create a virtual device in Device Manager. Start your project with `npx expo start`, then press `i` for iOS or `a` for Android. Test on a real device as well.

## iOS Simulator

1. Install Xcode from the Mac App Store.
2. Open Xcode once and accept the licence.
3. Run `npx expo start` and press `i`.

## Android Emulator

1. Install Android Studio.
2. Open **Device Manager** and create a virtual device.
3. Start the emulator.
4. Run `npx expo start` and press `a`.

## Real devices

Install Expo Go, scan the QR code and make sure the phone and computer are on the same network.

## Troubleshooting

- Emulator slow: enable hardware acceleration and give it enough memory.
- App not found: restart the dev server.
- Network errors: check Wi-Fi and firewalls.

## The bottom line

Simulators for speed, real devices for truth.

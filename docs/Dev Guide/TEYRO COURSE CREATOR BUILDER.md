**🟪 TEYRO CREATOR REQUIREMENTS (SYSTEM LEVEL)**

Everything a creator submits must fit this:

Course → Modules → Lessons → Steps (Learn → Apply → Reflect → Deepen)

**🟦 1. COURSE-LEVEL REQUIREMENTS**

These define the **transformation**, not just the content.

**🔹 Core Course Identity**

-   Course Title

-   Subtitle (Outcome-focused)

-   Category (UI Design, Dev, etc.)

-   Level:

    -   Beginner / Intermediate / Advanced

**🔹 Transformation Definition (CRITICAL)**

👉 This is where most platforms fail.

Creator must define:

**1. Starting Point**

"This course is for people who..."

**2. End Outcome**

"By the end, you'll be able to..."

**3. Real Outputs**

-   Projects user will complete

-   Skills they will gain

**🔹 Learning Commitment**

-   Total duration (hours)

-   Estimated completion time:

    -   e.g. "7 days (20 min/day)"

**🔹 Course Structure**

-   Number of modules

-   Number of lessons

**🔹 Social Proof / Credibility**

-   Instructor bio

-   Experience

-   Portfolio / proof

**🔹 Course Assets**

-   Thumbnail / cover

-   Preview lesson (mapped to engine, not random video)

**🟪 2. MODULE / PATH STRUCTURE**

Instead of "Section 1, 2, 3..."

Creator defines:

👉 **Learning Phases**

Example:

-   Foundations

-   Application

-   Real Projects

Each module must include:

-   Title

-   Goal:

> "In this module, you will..."

-   Lessons inside

**🟩 3. LESSON-LEVEL REQUIREMENTS (CORE OF YOUR SYSTEM)**

This is where Teyro becomes different.

Each lesson must follow:

Learn → Apply → Reflect → Deepen

**🔹 A. LEARN (INPUT)**

Creator provides:

-   Short video (1--5 min chunks) OR

-   Text explanation OR

-   Demo walkthrough

👉 Must be broken into micro-units

**🔹 B. APPLY (MOST IMPORTANT)**

This is where creators struggle.

They must provide:

**1. Context Scenario**

"You're designing a landing page..."

**2. Task / Question**

-   Multiple choice

-   Fix this

-   Choose best option

-   Build something

**3. Correct Answer / Expected Output**

-   Right answer

-   Or expected result

**4. Explanation**

-   Why it's correct

-   Why others are wrong

👉 This powers:

-   Step 3 (Engage)

-   Step 4 (Feedback)

**🔹 C. REFLECT**

Creator must define:

-   Key takeaway prompt

> "What did you learn here?"

-   Suggested answers (optional chips)

👉 This powers retention.

**🔹 D. DEEPEN (RESOURCES)**

Creator provides structured resources:

**Resource Types:**

-   PDF

-   Notes

-   Templates

-   Demo files

-   External links

Each resource must include:

-   Title

-   Type

-   Estimated time:

    -   "2 min read"

    -   "5 min watch"

Optional:

-   XP reward value

**🔹 E. NEXT STEP LINKING**

Each lesson must define:

-   Next lesson

-   Or next path

👉 This powers Step 6 (Continue)

**🟨 4. AI SUPPORT DATA (VERY IMPORTANT FOR TEYRO)**

This is your hidden advantage.

Creators must provide:

**🔹 Simplified Explanation**

"Explain this concept simply"

**🔹 Real-world Example**

"Give a practical example"

**🔹 Common Mistakes**

"What learners usually get wrong"

👉 This feeds:

-   AI assistant

-   contextual help

**🟧 5. INTERACTION METADATA (SYSTEM SIDE)**

This is not visible to users, but required.

For each lesson step:

-   Step type:

    -   Learn / Apply / Reflect / Deepen

-   Difficulty level

-   Estimated time

-   XP reward

👉 This powers:

-   personalization

-   progress tracking

-   gamification

## Twelve topics, three courses

The founder listed twelve titles. Many overlap heavily: "Negotiate Without Feeling Awkward" and "Ask for What You Want" teach the same skills as "Negotiation Skills for Beginners". Twelve separate 50-lesson courses would repeat themselves. So, as with the Business set, this pass builds **three short courses (5 chapters × 10 lessons)**. Each course takes in the related topics as chapters, so all twelve are covered:

| Course | Storyline | Covers these titles |
|---|---|---|
| **1. Negotiation Skills for Beginners** | *Ada Asks* | Negotiation Skills for Beginners · How to Negotiate Without Feeling Awkward · How to Ask for What You Want · How to Find Win-Win Solutions |
| **2. How to Handle Difficult Negotiations** | *Arjun's Big Contract* | How to Handle Difficult Negotiations · How to Recognize Common Negotiation Tactics · How to Handle Unreasonable Requests |
| **3. How to Manage Conflict at Work** | *Grace Keeps the Peace* | How to Manage Conflict at Work · How to De-escalate an Argument · How to Resolve Misunderstandings · How to Respond to Unfair Criticism · How to Set Boundaries Without Damaging Relationships |

Any of the merged titles can later become its own short course (for example, a stand-alone *How to Set Boundaries* that goes deeper than Course 3's Chapter 5). The outlines mark which chapter each title lives in, so that's a simple split.

## Order

Course 1 → 2 → 3 is the recommended order: asking, then pushing back, then repairing. Each course also works on its own, and each one's first lesson needs no earlier course.

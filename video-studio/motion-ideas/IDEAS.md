# Motion Explainer idea bank (`/motion-explainer`)

Separate from `ideas/IDEAS.md` (the `/make-videos` bank). One row per idea.
- **Statuses:** `idea` → `approved <date>` (only the person running the session approves, in chat) → `produced <date>`. Or `rejected <date> <reason>`.
- **Rules:**
  - One video at a time.
  - Never script an idea that isn't `approved`.
  - Every number in a video needs a primary source, checked on the day of scripting.

**Topic test (all four must pass; doc §2.1, §2.3):**
1. **Daily use:** it's something the viewer already uses (AI chat, apps, phone, web, passwords, Git at work…).
2. **Real depth:** it explains *how it really works* with real numbers. Never "5 tips", never basics-only.
3. **Room for chapters:** it fills 2:00–2:55 with 6–9 problem→fix chapters and has one twist.
4. **Fits Teyro:** it fits the coding / AI tracks, so the Teyro bridge and outro feel natural.

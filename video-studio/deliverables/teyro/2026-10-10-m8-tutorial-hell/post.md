## Reply bank (first hour)
- **"What app is this?"** → It's Teyro: short coding and AI lessons where you write real code with instant feedback, plus streaks, leagues and friends. It's free to start. Search Teyro or go to teyro.app.
- **"Is the Git course really free?"** → Yes. "Learn Git, GitHub, and GitHub Actions" is free on Teyro: 57 lessons, from your first commit to GitHub Actions.
- **"That study was about reading, not coding"** → True. Roediger & Karpicke (2006) used prose passages. Recall beating re-reading is one of the best-replicated findings in learning science, and writing code from memory is recall.
- **"Source for 34 vs 22?"** → Freeman et al., *PNAS* (2014): a meta-analysis of 225 studies of college STEM courses. Failure rates were about 34% with lectures and about 22% with active learning.
- **"So tutorials are bad?"** → No. Watch to get the idea, then close the video and write the code yourself. Watching *only* is the trap.

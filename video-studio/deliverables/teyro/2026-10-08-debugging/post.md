## Reply bank (first hour)
- **"How do I add a logpoint?"** → In Chrome DevTools > Sources, right-click a line number and choose "Add logpoint". Type the expression to log.
- **"git bisect commands?"** → git bisect start, git bisect bad (current), git bisect good <old commit>, then mark each step good/bad. git bisect reset when done.

## 2024-05-24 - Visual Required Form Indicators
**Learning:** Browsers natively validate `required` fields and screen readers announce them, but sighted users often lack immediate visual cues unless explicitly designed. Adding a simple `*` inside the label is a common pattern, but it must include `aria-hidden="true"` so screen readers do not redundantly read "star" alongside "required".
**Action:** When creating or updating form components (Input, Textarea, Select, etc.), check for the `required` prop and conditionally render a visual indicator (like an asterisk) with `aria-hidden="true"` to provide a better experience for sighted users without degrading the experience for screen reader users.

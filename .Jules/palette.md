## 2024-06-21 - [Form Validation Accessibility]
**Learning:** Relied on color alone for field error validation states, failing WCAG 1.4.1. Also learned that the native `required` HTML attribute should be passed down to custom input/textarea wrappers, and any visual asterisk should be explicitly hidden via `aria-hidden="true"` since screen readers already announce the native required state.
**Action:** Always add an inline icon (e.g. `AlertCircle`) and `role="alert"` alongside error messages. Pass down the `required` prop to conditionally render the asterisk and explicitly set `aria-hidden="true"` on the asterisk span.
